STEP 1 · THE BIG IDEA

Everything on screen starts with a widget

A Flutter widget is a small description of part of the user interface. A word, an icon, a picture, and even the top bar can each be a widget.

By the end: You can name common widgets, read simple widget code, explain parent and child widgets, and trace a small widget tree.

Think of widgets as building pieces

Widgets describe

A widget tells Flutter what a part of the screen should look like.

Widgets have settings

Settings such as text, color, or icon shape are called properties.

Widgets fit together

One widget can contain another. This creates a widget tree.

A widget is not the picture itself.

It is a description Flutter uses to draw the picture. When the description changes, Flutter updates the screen.

Read one widget at a time

A tiny example

READING TIP

Start at the outside: “This is a Text widget.” Then read each property: “It shows these words and centers them.”

Punctuation has a job

Parentheses ( )

Hold the values and properties given to the widget.

Comma ,

Separates values. A trailing comma also helps Flutter format the code clearly.

Colon :

Separates a named property from its value.

Quotes ' '

Mark text values, also called strings.

STEP 3 · PARENTS AND CHILDREN

Widgets form a tree

When one widget contains another widget, Flutter code has a parent-and-child shape. A whole screen becomes a widget tree.

Parent widget

A widget that contains another widget. A Card can be the parent of Text.

Child widget

A widget placed inside a parent. The property is often named child.

Card(
  child: Text('My first card'),
)
Say it aloud: “A Card has one child. Its child is Text.”

STEP 5 · PICTURES

Show pictures with Image

An Image widget can load a picture from your project or from the internet.

A picture from your project

Image.asset(
  'assets/images/profile.png',
  width: 160,
  height: 160,
  fit: BoxFit.cover,
)
Image.asset

Loads a picture included in your project. The asset must also be listed correctly in pubspec.yaml.

Image.network

Loads a picture from a web address. It needs a network connection.

Size and fit

width and height set the image area. BoxFit.cover fills that area. Some edges may be cropped so the picture does not look stretched.

Why might an asset image not appear?
  • The file path or letter case is wrong.
  • The asset was not declared in pubspec.yaml.
  • The YAML indentation is wrong.

Check the path carefully, then restart the app if needed.

STEP 6 · SURFACES

Give content a surface

Container and Card can both hold a child, but they communicate different ideas.

Container

A flexible box for size, space, color, borders, and decoration. Use it when you need to control the box around one child.

Card

A Material surface that groups related information. It looks like one meaningful item.

Container example

Container(
  padding: const EdgeInsets.all(16),
  color: Colors.amber,
  child: Text('Important note'),
)

Card example

Card(
  elevation: 3,
  child: Padding(
    padding: const EdgeInsets.all(16),
    child: Text('Flutter Study Group'),
  ),
)
You do not need to learn Padding yet. Here it simply adds breathing room inside the card.
DO NOT MEMORIZE

Focus on the shape: Card → child → Text. You can look up property names when you need them.

STEP 7 · APP SHELL

Frame a screen with app-shell widgets

Some widgets describe the screen around your content. They help people know where they are and move to main areas.

AppBar

The bar at the top of a screen. It often contains a title and screen actions.

BottomNavigationBar

The navigation area at the bottom. It switches between a few main destinations.

They go into Scaffold

Scaffold gives a Material screen its basic slots. For now, only notice where each widget goes.

Scaffold(
  appBar: AppBar(
    title: Text('Library'),
  ),
  body: Card(
    child: Text('Book of the day'),
  ),
  bottomNavigationBar: BottomNavigationBar(
    items: const [
      BottomNavigationBarItem(
        icon: Icon(Icons.home), label: 'Home',
      ),
      BottomNavigationBarItem(
        icon: Icon(Icons.person), label: 'Profile',
      ),
    ],
  ),
)
NOTICE

This example shows nesting, not a layout lesson. You will learn how to arrange several body widgets in the next codelabs.
