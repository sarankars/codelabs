# Flutter Widgets and the Widget Tree

This beginner codelab introduces Flutter's main idea: a user interface is made from widgets. Learners explore small, visible widgets first, then see how parent and child widgets form a widget tree. It also introduces common app-shell widgets without teaching layout widgets such as `Row` or `Column`.

## Lesson path

1. What a widget is
2. Reading a widget
3. How the widget tree works
4. Text and Icon
5. Image
6. Container and Card
7. AppBar and BottomNavigationBar
8. Read a small screen tree
9. Practice and review
