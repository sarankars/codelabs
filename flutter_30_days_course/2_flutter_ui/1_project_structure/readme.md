# Flutter Project Structure

This codelab turns a learner’s Dart knowledge into their first readable Flutter project. It explains the files created by Flutter Create, how an app starts, and a small feature-first organization that remains comfortable as the UI grows.

## Plan

1. What Flutter creates
2. The app entry point and runApp
3. MaterialApp and the root widget
4. The lib folder and main.dart
5. Assets and pubspec.yaml
6. A small feature-first structure
7. Practice: organize a profile screen
