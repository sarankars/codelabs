STEP 1 · START HERE

Understanding Flutter's Layout System

Flutter interfaces are widget trees. Layout widgets decide how their children are sized, arranged, aligned, layered, and scrolled.

By the end: You can choose an appropriate layout widget, explain Flutter's constraint flow, build nested layouts, fix common overflows, and adapt a screen to different widths.

The rule behind every layout

1. Constraints go down

A parent tells each child the minimum and maximum size it may use.

2. Sizes go up

Each child selects a permitted size and reports it back.

3. Parents position children

The parent decides where each child appears inside its own space.

4. The tree repeats the process

Every child can become a parent to another widget.

CORE IDEA

A widget cannot usually choose any size it wants. Its final size must satisfy the constraints received from its parent.

Start with the screen shell

MaterialApp(
  home: Scaffold(
    appBar: AppBar(title: const Text('Widget Layouts')),
    body: const SafeArea(
      child: Text('Safe screen content'),
    ),
  ),
)
WidgetResponsibility
MaterialAppProvides the Material application environment.
ScaffoldCreates a standard screen structure.
SafeAreaKeeps content away from system intrusions.
Text, Icon, Image, Card, DividerProvide visible content for the layout.

Quick check

Who normally decides where a child is positioned?

Correct. The parent positions the child after the child reports a permitted size.
STEP 2 · ONE CHILD

Single-Child Layout Widgets

Begin with widgets that receive one child. They make sizing, spacing, and positioning easy to see.

Container

Size, decorate, space, and align one child.

Center

Place one child in the middle of the available area.

Padding

Add empty space around one child.

SizedBox

Create a fixed-size box or an intentional gap.

Align

Place one child at a selected position.

1. Container

Container is a convenience widget. It combines common sizing, spacing, alignment, decoration, and transformation features around one child.

PropertyPurposeCommon value
childThe widget inside the container.Text(...)
width / heightRequest a specific size.width: 240
paddingSpace between the boundary and child.EdgeInsets.all(16)
marginSpace outside the container.EdgeInsets.symmetric(...)
alignmentPosition the child inside the container.Alignment.center
colorSet a simple background color.Colors.blue
decorationAdd color, border, radius, gradient, or shadow.BoxDecoration(...)
constraintsAdd minimum or maximum size rules.BoxConstraints(...)
Container(
  width: 260,
  height: 120,
  margin: const EdgeInsets.all(16),
  padding: const EdgeInsets.symmetric(
    horizontal: 20,
    vertical: 12,
  ),
  alignment: Alignment.center,
  decoration: BoxDecoration(
    color: Colors.blue.shade100,
    border: Border.all(color: Colors.blue, width: 2),
    borderRadius: BorderRadius.circular(16),
    boxShadow: const [
      BoxShadow(
        color: Colors.black26,
        blurRadius: 8,
        offset: Offset(0, 4),
      ),
    ],
  ),
  child: const Text('Flutter Course'),
)
IMPORTANT

Do not provide both color and decoration. When using BoxDecoration, put the background color inside the decoration.

2. Center

Center positions its child at the center of the space its parent provides.

PropertyPurpose
childThe widget to center.
widthFactorMakes Center's width a multiple of the child's width when possible.
heightFactorMakes Center's height a multiple of the child's height when possible.
Container(
  width: 280,
  height: 140,
  color: Colors.blue.shade50,
  child: const Center(
    child: Text(
      'Centered message',
      style: TextStyle(fontSize: 20),
    ),
  ),
)
Most common usage: Students will usually set only child. Introduce widthFactor and heightFactor as optional sizing controls, not mandatory settings.

3. Padding

Padding inserts empty space around its child. Unlike margin, this is an explicit layout widget in the widget tree.

PropertyPurpose
paddingThe amount of space to insert.
childThe widget placed inside that space.
const Padding(
  padding: EdgeInsets.only(
    left: 24,
    top: 16,
    right: 24,
    bottom: 8,
  ),
  child: Text('Content with breathing room'),
)
All sides

EdgeInsets.all(16)

Horizontal and vertical

EdgeInsets.symmetric(horizontal: 24, vertical: 12)

Selected sides

EdgeInsets.only(left: 16, top: 8)

Different value per side

EdgeInsets.fromLTRB(16, 8, 24, 12)

4. SizedBox

SizedBox can give its child a requested size or create an empty, predictable gap between widgets.

Property / constructorPurpose
widthRequest a fixed width.
heightRequest a fixed height.
childOptionally constrain one child.
SizedBox.expandFill all permitted width and height.
SizedBox.shrinkRequest the smallest permitted size.
Column(
  children: [
    const Text('Course title'),

    // Empty vertical gap
    const SizedBox(height: 16),

    // A child with a requested size
    SizedBox(
      width: 220,
      height: 56,
      child: ElevatedButton(
        onPressed: () {},
        child: const Text('Start course'),
      ),
    ),
  ],
)
LAYOUT NOTE

A SizedBox still obeys its parent's constraints. If a parent does not permit 220 pixels of width, Flutter cannot guarantee that requested width.

5. Align

Align places its child at a selected point inside the available space. Use it when centering alone is not enough.

PropertyPurposeCommon value
alignmentSelect the child's position.Alignment.bottomRight
childThe widget to position.Icon(...)
widthFactorSize Align's width relative to its child.2
heightFactorSize Align's height relative to its child.2
Container(
  width: 280,
  height: 140,
  color: Colors.orange.shade100,
  child: const Align(
    alignment: Alignment.bottomRight,
    child: Padding(
      padding: EdgeInsets.all(12),
      child: Icon(Icons.settings, size: 32),
    ),
  ),
)
Common alignment valuesPosition
Alignment.topLeftUpper-left corner
Alignment.topCenterMiddle of the top edge
Alignment.centerCenter
Alignment.centerRightMiddle of the right edge
Alignment.bottomRightLower-right corner
REMEMBER

Choose the smallest widget that clearly expresses the intent: Padding for spacing, Center for centering, Align for positioning, SizedBox for size or gaps, and Container when several concerns must be combined.

STEP 3 · MULTIPLE CHILDREN

Row, Column & the Two Axes

Row arranges children horizontally. Column arranges them vertically. Both use a main axis and a cross axis.

WidgetMain axisCross axis
RowHorizontalVertical
ColumnVerticalHorizontal

1. Row

Row lays out multiple children from left to right by default. Its main axis is horizontal, so main-axis properties control horizontal placement.

PropertyPurposeCommon value
childrenThe widgets arranged horizontally.[Icon(...), Text(...)]
mainAxisAlignmentDistributes children horizontally.MainAxisAlignment.spaceBetween
crossAxisAlignmentAligns children vertically.CrossAxisAlignment.center
mainAxisSizeChooses whether the Row uses maximum or minimum horizontal space.MainAxisSize.max
textDirectionControls the horizontal start direction.TextDirection.ltr
verticalDirectionControls which vertical side is treated as the start.VerticalDirection.down
Container(
  height: 72,
  padding: const EdgeInsets.symmetric(horizontal: 16),
  color: Colors.blue.shade50,
  child: const Row(
    mainAxisAlignment: MainAxisAlignment.spaceBetween,
    crossAxisAlignment: CrossAxisAlignment.center,
    children: [
      Icon(Icons.menu),
      Text(
        'Student Dashboard',
        style: TextStyle(fontWeight: FontWeight.bold),
      ),
      Icon(Icons.notifications),
    ],
  ),
)
OVERFLOW

A Row keeps its children on one horizontal line. Long or wide children can overflow. Later, use Expanded, Flexible, or Wrap according to the intended design.

2. Column

Column lays out multiple children from top to bottom by default. Its main axis is vertical, so main-axis properties control vertical placement.

PropertyPurposeCommon value
childrenThe widgets arranged vertically.[Text(...), Text(...)]
mainAxisAlignmentDistributes children vertically.MainAxisAlignment.center
crossAxisAlignmentAligns children horizontally.CrossAxisAlignment.start
mainAxisSizeChooses whether the Column uses maximum or minimum vertical space.MainAxisSize.min
textDirectionHelps determine horizontal start and end.Usually inherited
verticalDirectionControls whether children begin at the top or bottom.VerticalDirection.down
Container(
  width: 280,
  padding: const EdgeInsets.all(16),
  color: Colors.orange.shade50,
  child: const Column(
    mainAxisSize: MainAxisSize.min,
    mainAxisAlignment: MainAxisAlignment.center,
    crossAxisAlignment: CrossAxisAlignment.start,
    children: [
      Text(
        'Flutter 30 Days',
        style: TextStyle(
          fontSize: 20,
          fontWeight: FontWeight.bold,
        ),
      ),
      SizedBox(height: 8),
      Text('Week 2 · Widget Layouts'),
      SizedBox(height: 4),
      Text('Progress: 35%'),
    ],
  ),
)
SCROLLING

A Column does not scroll. If its content is taller than the available height, choose a suitable scrolling layout such as SingleChildScrollView or ListView.

Properties shared by Row and Column

PropertyUseful valuesWhat changes?
mainAxisAlignmentstart, center, end, spaceBetween, spaceAround, spaceEvenlyPlacement and distribution along the main axis.
crossAxisAlignmentstart, center, end, stretch, baselineAlignment along the cross axis.
mainAxisSizemax, minWhether the layout claims all available main-axis space or hugs its children.
Baseline note: CrossAxisAlignment.baseline is mainly useful in a Row containing text of different sizes. It also requires an appropriate textBaseline.

3. Nest Row and Column

Real screens usually combine both widgets. In this profile header, the outer Row arranges the avatar and information horizontally, while the inner Column arranges the two text widgets vertically.

const Row(
  crossAxisAlignment: CrossAxisAlignment.center,
  children: [
    CircleAvatar(
      radius: 28,
      child: Icon(Icons.person),
    ),
    SizedBox(width: 12),
    Column(
      mainAxisSize: MainAxisSize.min,
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        Text(
          'Aarav Sharma',
          style: TextStyle(fontWeight: FontWeight.bold),
        ),
        Text('Flutter Student'),
      ],
    ),
  ],
)
Experiment: Change one alignment property at a time. Before running the app, ask whether it affects the horizontal or vertical axis for that particular widget.

Quick check

What does crossAxisAlignment control in a Row?

Correct. A Row's cross axis is vertical.
STEP 4 · FLEX SPACE

Expanded, Flexible & Spacer

Flex widgets decide how unused space in a Row or Column is distributed.

1. Expanded

Expanded gives a child a share of the remaining main-axis space and forces the child to fill that share.

PropertyPurposeDefault
childThe widget that must fill its allocation.Required
flexSets this child's share relative to other flex children.1
Row(
  children: [
    Expanded(
      flex: 2,
      child: Container(
        height: 80,
        color: Colors.blue,
        child: const Center(child: Text('2 shares')),
      ),
    ),
    const SizedBox(width: 8),
    Expanded(
      child: Container(
        height: 80,
        color: Colors.orange,
        child: const Center(child: Text('1 share')),
      ),
    ),
  ],
)
REMEMBER

flex: 2 does not mean 200 pixels. It means twice the share of a sibling using flex: 1.

2. Flexible

Flexible gives a child permission to use flexible space, but its fit decides whether the child must fill that allocation.

PropertyPurposeDefault
childThe widget allowed to flex.Required
flexSets its relative share of remaining space.1
fitloose permits a smaller child; tight forces it to fill.FlexFit.loose
const Row(
  children: [
    Flexible(
      fit: FlexFit.loose,
      child: Text(
        'A long course title that should wrap instead of overflowing',
      ),
    ),
    SizedBox(width: 8),
    Icon(Icons.arrow_forward),
  ],
)
Expanded versus Flexible: Expanded behaves like a Flexible with FlexFit.tight. The common Flexible case uses a loose fit.

3. Spacer

Spacer inserts flexible empty space between children. It is useful for pushing widgets apart without hard-coded gaps.

PropertyPurposeDefault
flexSets the empty space's share relative to other flex widgets.1
const Row(
  children: [
    Icon(Icons.book),
    SizedBox(width: 8),
    Text('Widget Layouts'),
    Spacer(),
    Text('35%'),
    SizedBox(width: 8),
    Icon(Icons.arrow_forward),
  ],
)
COMMON ERROR

All three widgets are designed for a Row, Column, or another Flex. Do not place them directly inside a Stack, ListView, or ordinary Container.

Quick check

Which widget forces its child to fill the allocated flex space?

Correct. Expanded uses a tight fit and forces its child to fill its allocation.
STEP 5 · CONTENT FLOW

Wrap Content Without Overflow

Wrap places children on another run when the current row or column runs out of room.

1. Wrap

Wrap arranges children sequentially and creates a new run whenever the current run lacks space.

PropertyPurposeCommon value
childrenThe widgets to arrange.A list of Chip widgets
directionSets the main direction of each run.Axis.horizontal
alignmentAligns children within a run.WrapAlignment.start
spacingGap between children in one run.8
runAlignmentAligns the collection of runs.WrapAlignment.start
runSpacingGap between runs.8
crossAxisAlignmentAligns children across each run.WrapCrossAlignment.center
verticalDirectionControls the vertical run direction.VerticalDirection.down
const Wrap(
  alignment: WrapAlignment.start,
  spacing: 8,
  runSpacing: 8,
  crossAxisAlignment: WrapCrossAlignment.center,
  children: [
    Chip(label: Text('Flutter')),
    Chip(label: Text('Dart')),
    Chip(label: Text('Firebase')),
    Chip(label: Text('REST API')),
  ],
)
Row

Keeps children on one horizontal line. It can overflow when they do not fit.

Wrap

Starts another run and exposes spacing and runSpacing.

Try it

Replace the Wrap with a Row, add more chips, and observe the overflow warning. Restore Wrap to fix the layout.

Quick check

Which property controls the gap between separate lines of wrapped children?

Correct. runSpacing controls the gap between runs; spacing controls the gap within one run.
STEP 6 · LAYERS

Stack, Positioned & IndexedStack

Linear layouts place widgets beside one another. A Stack lets widgets overlap.

1. Stack

Stack layers children from back to front. The first child is painted at the back and the last child appears on top.

PropertyPurposeCommon value
childrenThe widgets to layer.Background followed by overlays
alignmentPositions non-positioned children.Alignment.center
fitControls how non-positioned children use the Stack's size.StackFit.loose
clipBehaviorDecides whether overflowing paint is clipped.Clip.hardEdge
textDirectionHelps resolve directional alignment.Usually inherited
SizedBox(
  width: 300,
  height: 170,
  child: Stack(
    alignment: Alignment.center,
    children: [
      Container(color: Colors.blue.shade700),
      const Icon(Icons.school, size: 72, color: Colors.white24),
      const Align(
        alignment: Alignment.bottomCenter,
        child: Padding(
          padding: EdgeInsets.all(16),
          child: Text(
            'Flutter Course',
            style: TextStyle(color: Colors.white, fontSize: 20),
          ),
        ),
      ),
    ],
  ),
)

2. Positioned

Positioned gives a child explicit offsets or dimensions inside its nearest Stack.

PropertyPurpose
childThe widget to place.
top, right, bottom, leftSet offsets from the Stack's edges.
width, heightRequest explicit dimensions when the corresponding edges do not already determine them.
Stack(
  clipBehavior: Clip.none,
  children: [
    const Icon(Icons.notifications, size: 42),
    Positioned(
      top: -2,
      right: -2,
      child: Container(
        width: 14,
        height: 14,
        decoration: const BoxDecoration(
          color: Colors.red,
          shape: BoxShape.circle,
        ),
      ),
    ),
  ],
)
COMMON ERROR

Positioned is a parent-data widget intended for a Stack. Do not place another layout widget between Positioned and its Stack.

3. IndexedStack

IndexedStack keeps multiple children in the tree but paints only the child selected by index.

PropertyPurposeCommon value
indexSelects the visible child.0
childrenThe pages or states to preserve.A list of screen widgets
alignmentAligns children inside the stack.AlignmentDirectional.topStart
sizingDetermines how the stack's size is calculated.StackFit.loose
const IndexedStack(
  index: 1,
  children: [
    Center(child: Text('Home page')),
    Center(child: Text('Courses page')),
    Center(child: Text('Profile page')),
  ],
)
Stack versus IndexedStack: Stack paints its children as layers. IndexedStack paints only one indexed child while preserving the others.
STEP 7 · SCROLLING

SingleChildScrollView & ListView

When content can exceed the viewport, choose a scrolling widget based on whether the content is a screen composition or a repeated sequence.

WidgetUse it for
ColumnA small vertical layout that fits.
SingleChildScrollView + ColumnA screen made from different sections that scroll together.
ListViewA scrollable sequence of known children.
ListView.builderA long or data-driven sequence built lazily.

1. SingleChildScrollView

SingleChildScrollView makes one child scrollable. It is a good fit for a screen composed from a limited number of different sections.

PropertyPurposeCommon value
childThe single widget that becomes scrollable.A Column
scrollDirectionSets vertical or horizontal scrolling.Axis.vertical
paddingAdds space around the scrollable content.EdgeInsets.all(16)
reverseReverses the scrolling direction.false
physicsCustomizes scroll behavior.Platform default
controllerReads or changes the scroll position.A ScrollController
SingleChildScrollView(
  padding: const EdgeInsets.all(16),
  child: Column(
    children: [
      const ProfileHeader(),
      const SizedBox(height: 16),
      const CourseSummary(),
      const SizedBox(height: 16),
      ...List.generate(6, (_) => const CourseCard()),
    ],
  ),
)
PERFORMANCE

This widget builds its entire child. For a long or unknown number of repeated items, use a lazy list instead.

2. ListView

ListView is a scrollable linear layout. Its default constructor is convenient when the number of children is small and known.

PropertyPurposeCommon value
childrenThe fixed list of child widgets.A short list
paddingInsets the list content.EdgeInsets.all(16)
scrollDirectionSets vertical or horizontal layout.Axis.vertical
reverseReverses item and scroll direction.false
physicsControls scrolling behavior.Platform default
shrinkWrapSizes the list from its content rather than maximum scroll-axis space.false
ListView(
  padding: const EdgeInsets.all(16),
  children: const [
    ListTile(leading: Icon(Icons.code), title: Text('Dart')),
    ListTile(leading: Icon(Icons.widgets), title: Text('Widgets')),
    ListTile(leading: Icon(Icons.view_quilt), title: Text('Layouts')),
  ],
)

3. ListTile

ListTile supplies a familiar leading-title-subtitle-trailing structure for one list row.

PropertyPurpose
leadingPlaces a widget before the title.
titleDisplays the primary content.
subtitleDisplays secondary content below the title.
trailingPlaces a widget at the end.
contentPaddingControls internal horizontal and vertical space.
onTapHandles a tap on the row.
selectedDisplays a selected visual state.
ListTile(
  leading: const CircleAvatar(child: Icon(Icons.code)),
  title: const Text('Widget Layouts'),
  subtitle: const Text('Day 8 · Flutter UI'),
  trailing: const Icon(Icons.chevron_right),
  contentPadding: const EdgeInsets.symmetric(horizontal: 16),
  onTap: () {
    debugPrint('Open lesson');
  },
)

4. ListView.builder

ListView.builder creates visible children on demand. Use it when items come from a collection or the list may become long.

PropertyPurpose
itemCountStates how many items the list contains.
itemBuilderBuilds the widget for a requested index.
itemExtentOptionally gives every item a fixed scroll-axis size.
paddingAdds space around the generated content.
scrollDirectionSets vertical or horizontal generation.
physicsCustomizes scrolling behavior.
final courses = ['Dart', 'Widgets', 'Layouts'];

ListView.builder(
  padding: const EdgeInsets.all(16),
  itemCount: courses.length,
  itemBuilder: (context, index) {
    return ListTile(
      leading: CircleAvatar(child: Text('${index + 1}')),
      title: Text(courses[index]),
    );
  },
)
COMMON ERROR

A vertical ListView placed directly inside a Column needs a bounded height. Wrap it with Expanded or provide an explicit height.

Need separators? Use ListView.separated with both an itemBuilder and a separatorBuilder.
STEP 8 · GRIDS

GridView & GridView.builder

A grid arranges scrollable items in rows and columns. Use a builder when the items come from data.

1. GridView.count

GridView.count is convenient when you know the column count and have a small, fixed collection of children.

PropertyPurposeCommon value
crossAxisCountSets the number of columns in a vertical grid.2
childrenThe fixed widgets displayed in the grid.A short list of cards
crossAxisSpacingSets horizontal space between columns.12
mainAxisSpacingSets vertical space between rows.12
childAspectRatioSets each tile's cross-axis to main-axis ratio.1
paddingAdds space around the complete grid.EdgeInsets.all(16)
scrollDirectionSets vertical or horizontal scrolling.Axis.vertical
GridView.count(
  padding: const EdgeInsets.all(16),
  crossAxisCount: 2,
  crossAxisSpacing: 12,
  mainAxisSpacing: 12,
  childAspectRatio: 1.2,
  children: const [
    Card(child: Center(child: Text('Dart'))),
    Card(child: Center(child: Text('Widgets'))),
    Card(child: Center(child: Text('Layouts'))),
    Card(child: Center(child: Text('Forms'))),
  ],
)

2. GridView.builder

GridView.builder creates grid tiles lazily from data. A grid delegate describes the column and sizing strategy.

PropertyPurpose
itemCountSets the number of items.
itemBuilderBuilds the tile for a requested index.
gridDelegateDefines the column count or maximum tile width and spacing.
paddingAdds space around the grid content.
scrollDirectionSets vertical or horizontal scrolling.
physicsCustomizes scroll behavior.
shrinkWrapSizes the grid from its content when necessary.
GridView.builder(
  padding: const EdgeInsets.all(16),
  itemCount: courses.length,
  gridDelegate: const SliverGridDelegateWithFixedCrossAxisCount(
    crossAxisCount: 2,
    crossAxisSpacing: 12,
    mainAxisSpacing: 12,
    childAspectRatio: 1.2,
  ),
  itemBuilder: (context, index) {
    return Card(child: Center(child: Text(courses[index])));
  },
)

3. Choose a grid delegate

DelegateUse it when
SliverGridDelegateWithFixedCrossAxisCountYou want an exact number of columns.
SliverGridDelegateWithMaxCrossAxisExtentYou want as many columns as fit while limiting each tile's maximum width.
const SliverGridDelegateWithMaxCrossAxisExtent(
  maxCrossAxisExtent: 220,
  crossAxisSpacing: 12,
  mainAxisSpacing: 12,
  childAspectRatio: 1.2,
)
NESTING

A GridView is already scrollable. When placing it inside another scrolling widget, first consider whether the design should use one scrollable parent. shrinkWrap can help in limited cases but costs extra layout work.

STEP 9 · SIZE RULES

Constraints & Sizing Widgets

These widgets express minimums, maximums, proportions, and scaling behavior.

ConstrainedBox

Adds minimum or maximum width and height rules.

AspectRatio

Preserves a width-to-height ratio such as 16:9.

FractionallySizedBox

Uses a fraction of the available parent size.

FittedBox

Scales its child to fit a box.

1. ConstrainedBox

ConstrainedBox adds minimum and maximum size rules to the constraints passed to its child.

PropertyPurpose
constraintsA BoxConstraints object containing minimum and maximum width and height.
childThe widget that receives the additional constraints.
ConstrainedBox(
  constraints: const BoxConstraints(
    minWidth: 200,
    minHeight: 80,
    maxWidth: 360,
  ),
  child: const ColoredBox(
    color: Colors.blue,
    child: Center(
      child: Text('At least 200 × 80 when permitted'),
    ),
  ),
)
BoxConstraints valueMeaning
minWidth / minHeightThe child cannot be smaller when the incoming constraints permit it.
maxWidth / maxHeightThe child cannot be larger than these limits.
BoxConstraints.tightFor(...)Requests exact dimensions.
BoxConstraints.expand()Uses the maximum permitted size.

2. AspectRatio

AspectRatio tries to size its child using a width-to-height ratio while still satisfying the parent's constraints.

PropertyPurpose
aspectRatioThe desired width divided by height.
childThe widget sized using that ratio.
AspectRatio(
  aspectRatio: 16 / 9,
  child: Container(
    color: Colors.black,
    child: const Center(
      child: Icon(Icons.play_arrow, color: Colors.white, size: 48),
    ),
  ),
)
Common ratios: 16 / 9 for video, 4 / 3 for traditional media, and 1 for a square.

3. FractionallySizedBox

FractionallySizedBox sizes its child as a fraction of the available parent size.

PropertyPurposeExample
widthFactorMultiplies the available width.0.8 means 80%
heightFactorMultiplies the available height.0.5 means 50%
alignmentPositions the child inside the available area.Alignment.center
childThe widget receiving the fractional size.A button or progress panel
FractionallySizedBox(
  widthFactor: 0.8,
  alignment: Alignment.center,
  child: Container(
    height: 56,
    color: Colors.blue,
    child: const Center(child: Text('80% of available width')),
  ),
)

4. FittedBox

FittedBox scales and positions its child inside the space it receives.

PropertyPurposeCommon value
fitChooses how the child is scaled.BoxFit.contain
alignmentPositions the scaled child.Alignment.center
clipBehaviorControls clipping when content exceeds the box.Clip.none
childThe widget to scale.Text, logo, or illustration
const SizedBox(
  width: 180,
  height: 50,
  child: FittedBox(
    fit: BoxFit.scaleDown,
    alignment: Alignment.centerLeft,
    child: Text('Flutter Development Course'),
  ),
)
Common BoxFitBehavior
containShows the complete child inside the box.
coverFills the box and may crop part of the child.
fitWidth / fitHeightFits one dimension.
scaleDownOnly makes the child smaller when necessary.
KEY LESSON

Writing width: 500 is a request, not an unconditional command. The parent constraints still determine what size is permitted.

STEP 10 · RESPONSIVE UI

MediaQuery, LayoutBuilder & OrientationBuilder

Responsive layouts react to their environment instead of assuming every device has the same width.

ToolQuestion it answers
MediaQueryWhat are the window, system padding, text scale, and keyboard conditions?
LayoutBuilderHow much space did this parent give this part of the UI?
OrientationBuilderIs the available area portrait or landscape?

1. MediaQuery

MediaQuery exposes information about the current window and system environment. Prefer the focused ...Of(context) methods when you only need one value.

Common accessInformation returned
MediaQuery.sizeOf(context)The current logical window width and height.
MediaQuery.orientationOf(context)Portrait or landscape orientation.
MediaQuery.paddingOf(context)Safe-area padding caused by system UI.
MediaQuery.viewInsetsOf(context)Fully obscured areas, commonly the on-screen keyboard.
MediaQuery.textScalerOf(context)The user's preferred text scaling behavior.
final size = MediaQuery.sizeOf(context);
final keyboardHeight = MediaQuery.viewInsetsOf(context).bottom;
final isTabletWidth = size.width >= 600;

return Padding(
  padding: EdgeInsets.only(bottom: keyboardHeight),
  child: Text(
    isTabletWidth ? 'Wide layout' : 'Compact layout',
  ),
);
DO NOT OVERUSE

A reusable card should not always make decisions from the full screen width. If it depends on the space its parent allocated, use LayoutBuilder.

2. LayoutBuilder

LayoutBuilder runs its builder with the BoxConstraints supplied by the parent. It is ideal for responsive components.

PropertyPurpose
builderReceives BuildContext and the parent's BoxConstraints, then returns the appropriate widget tree.
LayoutBuilder(
  builder: (context, constraints) {
    final isWide = constraints.maxWidth >= 600;

    return isWide
        ? const Row(
            children: [
              Expanded(child: CourseCard()),
              SizedBox(width: 16),
              Expanded(child: CourseCard()),
            ],
          )
        : const Column(
            children: [
              CourseCard(),
              SizedBox(height: 16),
              CourseCard(),
            ],
          );
  },
)
Constraint valueMeaning
maxWidthMaximum width this component may use.
maxHeightMaximum height this component may use.
minWidth / minHeightThe component cannot be smaller than these values.
hasBoundedWidth / hasBoundedHeightWhether a finite maximum exists on that axis.

3. OrientationBuilder

OrientationBuilder rebuilds according to whether its available area is wider than it is tall.

PropertyPurpose
builderReceives BuildContext and an Orientation, then returns the chosen layout.
OrientationBuilder(
  builder: (context, orientation) {
    if (orientation == Orientation.landscape) {
      return const Row(
        children: [
          Expanded(child: CourseCard()),
          Expanded(child: CourseCard()),
        ],
      );
    }

    return const Column(
      children: [CourseCard(), CourseCard()],
    );
  },
)
Important: Orientation alone does not describe all available space. A small landscape area can still be narrow. Width-based decisions with LayoutBuilder are often more precise.
RULE OF THUMB

Prefer LayoutBuilder when a component depends on its allocated space. Use MediaQuery when you genuinely need information about the window or system environment.
