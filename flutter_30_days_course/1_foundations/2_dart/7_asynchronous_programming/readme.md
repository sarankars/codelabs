# Asynchronous Programming

This codelab teaches how Dart handles work that completes later, such as network requests, file operations, and timers. Learners will be ready to read and write the asynchronous code common in Flutter apps.

## Plan

1. Synchronous versus asynchronous work
2. `Future` and a value that arrives later
3. Creating and consuming futures
4. `async` and `await`
5. Error handling with `try`, `catch`, `finally`, and future errors
6. Running independent futures together
7. `Stream` and multiple values over time
8. Listening to streams and handling stream errors
9. `async*` and generators (introduction)
10. Practice: load data, show loading/error/success states, and consume updates
