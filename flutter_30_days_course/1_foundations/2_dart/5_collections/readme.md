# Collections

This codelab covers Dart's ways to work with groups of values. Lists, sets, maps, and `Iterable` operations underpin most app data and Flutter widget-building patterns.

## Plan

1. What collections are and when to choose each kind
2. Lists: creation, access, updates, and common methods
3. Sets: uniqueness and membership
4. Maps: keys, values, and lookups
5. `Iterable` and lazy collection operations
6. Iteration with loops and callbacks
7. Transforming values with `map`
8. Filtering with `where`
9. Searching with `firstWhere`, `contains`, and related methods
10. Sorting and ordering values
11. Collection `if`, collection `for`, and the spread operator
12. Nested collections and generic collection types
13. Practice: turn app data into display-ready values and widget inputs
