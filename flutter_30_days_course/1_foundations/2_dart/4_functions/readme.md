# Functions

This codelab shows how to package behaviour into reusable units. Learners will write functions with clear inputs and outputs, then use callbacks and closures in the same way Flutter APIs do.

## Plan

1. What functions are and why they improve program design
2. Defining and calling functions
3. Parameters and return values
4. Optional positional parameters
5. Named parameters, default values, and `required`
6. Concise arrow functions
7. Anonymous functions
8. Function types and functions as values
9. Higher-order functions
10. Callbacks and closures
11. Practice: create validation, formatting, and event-handler functions
