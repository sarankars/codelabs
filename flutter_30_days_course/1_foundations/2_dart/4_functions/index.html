STEP 1 · START HERE

Functions in Dart

A function is a named piece of behavior you can call whenever you need it. In Dart, functions are everywhere—and understanding them makes Flutter code much easier to read and write.

By the end: You will be able to declare, call, parameterize, compose, and pass Dart functions with confidence.

Why functions matter

Imagine a coffee machine. You press one button, and a repeatable process happens: grind, brew, pour. A function is similar: you give it a name, optionally give it information, and let it perform a defined job.

Reuse

Write behavior once and call it many times.

Organize

Break a large problem into small, understandable jobs.

Test

Small functions are easier to reason about and test.

Compose

Functions can work together and even be passed around as values.

REMEMBER

A function describes behavior. Calling the function is what actually performs that behavior.

STEP 2 · BASICS

Declare & call a function

Start with the simplest useful function: a named block of code that accepts no input and returns no value.

The basic shape

returnType functionName() {
  // statements
}
void sayHello() {
  print('Hello, Dart!');
}

void main() {
  sayHello();
  sayHello();
}
Expected Output
Hello, Dart!
Hello, Dart!

Read it in three moves

  1. void says the function does not return a value.
  2. sayHello is the function's name.
  3. sayHello(); calls the function.
COMMON MISTAKE

Defining a function does not automatically run it. You need to call it, usually with parentheses: sayHello();.

Quick check

Which line actually calls sayHello?

Correct. The declaration creates the function; the call executes it.
STEP 3 · INPUT

Parameters & arguments

Functions become more useful when they can receive information. A parameter is the variable in the function definition; an argument is the value you pass when calling it.

void greet(String name) {
  print('Hello, $name!');
}

void main() {
  greet('Asha');
  greet('Rahul');
}
Expected Output
Hello, Asha!
Hello, Rahul!
Parameter

String name is declared by the function and acts like a local variable.

Argument

'Asha' is the actual value supplied at the call site.

Multiple positional parameters

double area(double width, double height) {
  return width * height;
}

The order matters: area(4, 3) means width = 4 and height = 3.

TYPE SAFETY

Dart checks the declared parameter types. A function expecting a double should receive a compatible value rather than an unrelated type.

STEP 4 · FLEXIBLE INPUT

Named & optional parameters

Named parameters make calls easier to read, especially when a function accepts several values. They are also a major part of idiomatic Flutter APIs.

Named parameters

void createUser({String name = 'Guest', int age = 18}) {
  print('$name is $age');
}

void main() {
  createUser(name: 'Maya', age: 21);
}
Expected Output
Maya is 21

The braces in the parameter list indicate named parameters. At the call site, use name: and age:.

Required named parameters

void createProfile({required String username}) {
  print('Profile: $username');
}

void main() {
  createProfile(username: 'pratham');
}
Key idea: Named does not automatically mean optional in every sense. A named parameter can be marked required, which makes the caller provide it.

Default values

A non-required named parameter can provide a default value. If the caller omits it, Dart uses that default.

FLUTTER CONNECTION

You will see named parameters constantly in Flutter, for example when configuring widgets. The syntax helps calls remain readable as APIs grow.

STEP 5 · OUTPUT

Return values & void

A function can produce a result. Declare its return type and use return to send a value back to the caller.

int add(int a, int b) {
  return a + b;
}

void main() {
  final result = add(10, 5);
  print(result);
}
Expected Output
15
Return type

int tells readers and Dart what kind of result this function produces.

Return statement

return a + b; sends the calculated value back to the caller.

When to use void

Use void when the function is intended to perform an action rather than provide a result to its caller.

void showWelcome() {
  print('Welcome!');
}
REMEMBER

Think command for many void functions and calculation/result for functions that return a value. This is a useful design heuristic, not an absolute rule.

STEP 6 · SHORTER SYNTAX

Arrow functions

When a function consists of one expression, Dart lets you use arrow syntax to express the same idea more compactly.

Block body 
int square(int n) {
  return n * n;
}
Expression body 
int square(int n) => n * n;

The => syntax means “return the value of this single expression.” You do not write return in the expression-bodied form.

Another example

bool isAdult(int age) => age >= 18;
COMMON MISTAKE

Arrow functions are for a single expression. If the function needs several statements, use a normal block body.

Quick check

Which is a valid expression-bodied function?

Correct. The expression after => is implicitly returned.
STEP 7 · FUNCTIONS AS VALUES

Anonymous functions & callbacks

In Dart, functions are first-class objects. That means you can store a function in a variable, pass it to another function, and return a function.

Anonymous function

final numbers = [1, 2, 3];

numbers.forEach((number) {
  print(number * 2);
});
Expected Output
2
4
6

The function passed to forEach has no name, so it is an anonymous function. It is also a callback: code that another function can call later.

Passing a named function

void printDouble(int value) {
  print(value * 2);
}

void main() {
  [1, 2, 3].forEach(printDouble);
}
IMPORTANT

printDouble passes the function itself. printDouble() would call it immediately and produce a result instead. Parentheses change the meaning.

Why this matters in Flutter

Callbacks are fundamental to event-driven UI. Buttons, gesture handlers, timers, and many framework APIs accept functions that run when something happens.

STEP 8 · SCOPE

Scope & local variables

A variable declared inside a function normally belongs to that function's local scope. Keeping temporary data local reduces accidental coupling between parts of your program.

void calculateTotal() {
  final price = 100;
  final tax = 18;
  final total = price + tax;

  print(total);
}

void main() {
  calculateTotal();
}

Here, price, tax, and total are local to calculateTotal. Code outside the function cannot simply refer to those names.

A useful mental model

Every function gets its own workspace. Parameters enter the workspace; local variables live there; a returned value can leave the workspace.

What about variables outside the function?
Functions can access names from surrounding scopes when those names are visible, but avoid relying on mutable global state unnecessarily. Passing required information as parameters generally makes functions easier to understand and test.
GOOD PRACTICE

Prefer functions that clearly communicate what they need through parameters and what they produce through return values.

STEP 9 · PRACTICE

Put it together

Now combine parameters, return values, named arguments, and an arrow function into a small piece of application logic.

double calculatePrice({
  required double price,
  double taxRate = 0.18,
}) {
  return price + (price * taxRate);
}

String formatPrice(double value) =>
    '₹${value.toStringAsFixed(2)}';

void main() {
  final total = calculatePrice(price: 100);
  print(formatPrice(total));
}
Expected Output
₹118.00
1. Input

price is required; taxRate has a default.

2. Calculation

calculatePrice returns a double.

3. Formatting

formatPrice uses an expression body.

4. Composition

The result of one function becomes the input of another.

TRY IT · Mini challenge

Write a function called discountedPrice that accepts a required price and a named discountPercent with a default of 10. It should return the discounted price.

Hint: price - (price * discountPercent / 100)

Reveal one possible solution 
double discountedPrice({
  required double price,
  double discountPercent = 10,
}) {
  return price - (price * discountPercent / 100);
}
