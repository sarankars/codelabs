# Dart Project Fundamentals

This final Dart codelab connects language knowledge to real projects. Learners will understand how a Dart or Flutter project is structured, how code is shared across files, and how dependencies and tooling fit together.

## Plan

1. The purpose and layout of a Dart project
2. Source files, entry points, and the `lib/` directory
3. Splitting code into files
4. Imports, library prefixes, and visibility
5. Packages and `pubspec.yaml`
6. Adding and using dependencies
7. Development dependencies and basic tooling
8. Formatting, static analysis, and tests
9. Reading error messages and debugging with `dart run`
10. Practice: organize a small command-line project before moving to Flutter
