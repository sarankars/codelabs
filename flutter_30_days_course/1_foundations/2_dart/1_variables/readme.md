# Variables and Dart Basics

This codelab introduces the building blocks of a Dart program: values, variables, types, and expressions. By the end, learners can declare clear, type-safe values and use them in small programs.

## Plan

1. Dart program structure: `main()`, statements, comments, and `print()`
2. Variable declaration, initialization, assignment, and reassignment
3. Core types: `int`, `double`, `num`, `String`, and `bool`
4. Type inference with `var` and explicit type annotations
5. Immutable values with `final` and compile-time constants with `const`
6. When (and when not) to use `dynamic`
7. Strings: quotes, multiline text, interpolation, and common operations
8. Arithmetic, comparison, logical, assignment, and conditional operators
9. Type conversion and basic type checks (`is`, `is!`, and `as`)
10. Practice: model simple app data such as a profile or product
