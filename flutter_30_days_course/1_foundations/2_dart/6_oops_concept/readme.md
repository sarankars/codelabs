# Object-Oriented Programming

This codelab introduces Dart's class-based model for organizing data and behaviour. It provides the foundation needed to understand Flutter widgets, controllers, models, and APIs.

## Plan

1. Object-oriented programming: objects, state, and behaviour
2. Defining classes and creating objects
3. Fields, methods, and instance members
4. Generative, named, and initializing constructors
5. Encapsulation and library-private members
6. Getters and setters
7. Inheritance and `super`
8. Method overriding and polymorphism
9. Abstract classes
10. Interfaces with `implements`
11. Code reuse with mixins
12. Factory constructors
13. `static` members and extension methods
14. Practice: model a small set of app-domain objects
