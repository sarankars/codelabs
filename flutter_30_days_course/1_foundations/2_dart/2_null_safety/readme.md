# Null Safety

This codelab explains how Dart prevents accidental use of missing values. Learners will choose between nullable and non-nullable types and handle absence explicitly—an essential skill for Flutter UI and data handling.

## Plan

1. What `null` means and how it differs from an empty value
2. Nullable and non-nullable types
3. Declaring nullable values with `?`
4. Safe member access with `?.`
5. Fallback values with `??`
6. Assigning only when needed with `??=`
7. The null assertion operator `!` and why it should be used sparingly
8. Flow analysis and type promotion after null checks
9. Delayed initialization with `late`
10. Nullable parameters and return values
11. Null safety in lists, sets, maps, and Flutter-style UI state
12. Practice: render sensible states for missing profile data
