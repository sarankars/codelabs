# Control Flow

This codelab teaches how a Dart program makes decisions and repeats work. These constructs are used constantly when deciding which Flutter widgets to show and when processing data.

## Plan

1. Expressions and statements
2. Branching with `if`, `else if`, and `else`
3. Conditional expressions: ternary `?:` and null-aware choices
4. Counting loops with `for`
5. Iterating values with `for-in`
6. Repeating work with `while` and `do-while`
7. Controlling loops with `break` and `continue`
8. Selecting cases with `switch` statements
9. Producing values with switch expressions
10. Practice: choose UI states and process a list of app items
