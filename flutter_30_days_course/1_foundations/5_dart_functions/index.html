STEP 1 · START HERE

Functions in Dart

A function is a named piece of code that does one job. You can run it whenever you need it. Functions appear everywhere in Dart and Flutter.

By the end: You will be able to write functions, give them input, get a result back, and pass a function to other code.

Why functions matter

Imagine a coffee machine. You press one button, and a repeatable process happens: grind, brew, pour. A function is similar: you give it a name, optionally give it information, and let it perform a defined job.

Reuse

Write behavior once and call it many times.

Organize

Break a large problem into small, understandable jobs.

Test

Small functions are easier to reason about and test.

Compose

Functions can work together and even be passed around as values.

REMEMBER

A function describes behavior. Calling the function is what actually performs that behavior.

STEP 2 · BASICS

Declare & call a function

Start with the simplest useful function: a named block of code that accepts no input and returns no value.

The basic shape

returnType functionName() {
  // statements
}
void sayHello() {
  print('Hello, Dart!');
}

void main() {
  sayHello();
  sayHello();
}
Expected Output
Hello, Dart!
Hello, Dart!

Read it in three moves

  1. void says the function does not return a value.
  2. sayHello is the function's name.
  3. sayHello(); calls the function.
COMMON MISTAKE

Defining a function does not automatically run it. You need to call it, usually with parentheses: sayHello();.

Quick check

Which line actually calls sayHello?

Correct. The declaration creates the function; the call executes it.
STEP 3 · INPUT

Parameters & arguments

Functions become more useful when you give them information. A parameter is the named space in the function; an argument is the real value you put into that space.

void greet(String name) {
  print('Hello, $name!');
}

void main() {
  greet('Asha');
  greet('Rahul');
}
Expected Output
Hello, Asha!
Hello, Rahul!
Parameter

String name is the label the function uses for incoming information.

Argument

'Asha' is the actual value you give the function when you call it.

Multiple positional parameters

double area(double width, double height) {
  return width * height;
}

The order matters: area(4, 3) means width = 4 and height = 3.

TYPE CHECK

Dart checks the type of a value. If a function expects a number such as double, give it a number—not text like 'hello'.

STEP 4 · FLEXIBLE INPUT

Named & optional parameters

Named parameters label each value in a function call. They make calls easier to read, especially when there are several values. You will see them often in Flutter.

Named parameters

void createUser({String name = 'Guest', int age = 18}) {
  print('$name is $age');
}

void main() {
  createUser(name: 'Maya', age: 21);
}
Expected Output
Maya is 21

The braces mean these are named parameters. When calling the function, write the label too: name: and age:.

Required named parameters

void createProfile({required String username}) {
  print('Profile: $username');
}

void main() {
  createProfile(username: 'pratham');
}
Key idea: a named parameter can still be required. When it has required, you must give that value when calling the function.

Default values

A non-required named parameter can provide a default value. If the caller omits it, Dart uses that default.

FLUTTER CONNECTION

You will see named parameters constantly in Flutter, for example when configuring widgets. The syntax helps calls remain readable as APIs grow.

STEP 5 · OUTPUT

Return values & void

A function can produce a result. Declare its return type and use return to send a value back to the caller.

int add(int a, int b) {
  return a + b;
}

void main() {
  final result = add(10, 5);
  print(result);
}
Expected Output
15
Return type

int tells readers and Dart what kind of result this function produces.

Return statement

return a + b; sends the calculated value back to the caller.

When to use void

Use void when the function is intended to perform an action rather than provide a result to its caller.

void showWelcome() {
  print('Welcome!');
}
REMEMBER

Think command for many void functions and calculation/result for functions that return a value. This is a useful design heuristic, not an absolute rule.

STEP 6 · SHORTER SYNTAX

Arrow functions

When a function consists of one expression, Dart lets you use arrow syntax to express the same idea more compactly.

Block body 
int square(int n) {
  return n * n;
}
Expression body 
int square(int n) => n * n;

The => form is a short way to return one value. Use it only when the function is one simple expression; do not write return after the arrow.

Another example

bool isAdult(int age) => age >= 18;
COMMON MISTAKE

Arrow functions are for a single expression. If the function needs several statements, use a normal block body.

Quick check

Which is a valid expression-bodied function?

Correct. The expression after => is implicitly returned.
STEP 7 · FUNCTIONS AS VALUES

Anonymous functions & callbacks

In Dart, a function can be treated like a value. You can put one in a variable or give one to another function.

Anonymous function

final numbers = [1, 2, 3];

numbers.forEach((number) {
  print(number * 2);
});
Expected Output
2
4
6

The function given to forEach has no name, so it is an anonymous function. It is also a callback: a function that another function runs for you.

Passing a named function

void printDouble(int value) {
  print(value * 2);
}

void main() {
  [1, 2, 3].forEach(printDouble);
}
IMPORTANT

printDouble passes the function itself. printDouble() would call it immediately and produce a result instead. Parentheses change the meaning.

Why this matters in Flutter

Callbacks are fundamental to event-driven UI. Buttons, gesture handlers, timers, and many framework APIs accept functions that run when something happens.

STEP 8 · SCOPE

Scope & local variables

A variable made inside a function normally stays inside that function. This keeps temporary information from affecting other parts of your program.

void calculateTotal() {
  final price = 100;
  final tax = 18;
  final total = price + tax;

  print(total);
}

void main() {
  calculateTotal();
}

Here, price, tax, and total are local to calculateTotal. Code outside the function cannot simply refer to those names.

A useful mental model

Think of every function as its own small workspace. Values come in through parameters, temporary variables stay inside, and a result can go back out with return.

What about variables outside the function?
A function can sometimes see values around it, but do not depend too much on changing global values. Passing in what a function needs usually makes it easier to read and test.
GOOD PRACTICE

Make it clear what a function needs and what it gives back. Use parameters for input and return for a result.

STEP 9 · PRACTICE

Put it together

Now use inputs, return values, named arguments, and an arrow function in one small app-style example.

double calculatePrice({
  required double price,
  double taxRate = 0.18,
}) {
  return price + (price * taxRate);
}

String formatPrice(double value) =>
    '₹${value.toStringAsFixed(2)}';

void main() {
  final total = calculatePrice(price: 100);
  print(formatPrice(total));
}
Expected Output
₹118.00
1. Input

price is required; taxRate has a default.

2. Calculation

calculatePrice returns a double.

3. Formatting

formatPrice uses the short arrow form.

4. Use the result

The total from one function is given to the next function.

TRY IT · Mini challenge

Write a function called discountedPrice that accepts a required price and a named discountPercent with a default of 10. It should return the discounted price.

Hint: price - (price * discountPercent / 100)

Reveal one possible solution 
double discountedPrice({
  required double price,
  double discountPercent = 10,
}) {
  return price - (price * discountPercent / 100);
}
STEP 10 · QUIZ

Recap & knowledge check

You now have the essential function toolkit for everyday Dart programming and a strong foundation for Flutter APIs.

The function checklist

declare call parameters named parameters required defaults return void arrow syntax anonymous functions callbacks scope

1. What does return do?

Correct. A return statement provides the function's result to its caller.

2. Which call uses named arguments?

Correct. The name: value syntax identifies named arguments.

3. What is a callback?

Correct. Callbacks are functions passed to other code for later invocation.

4. Which named parameter must callers provide?

Correct. required makes a named argument mandatory at the call site.

5. When is void the right return type?

Correct. Use void for a function whose caller does not receive a result.

6. Why would you choose a block body instead of =>?

Correct. Arrow syntax is for one expression; a block body can contain several statements.

7. Where can a local variable declared inside a function be used?

Correct. Local variables belong to the function or block where they are declared.
STEP 11 · FINAL TASK

Build checkout helpers

Create a small set of functions that could sit behind a Flutter checkout screen. Give every function one clear responsibility.

BUILD IT · Checkout helpers

  1. Write double calculateSubtotal(List<double> prices) to add the item prices.
  2. Write double applyDiscount({required double subtotal, double discountPercent = 0}) that returns the discounted amount.
  3. Write an arrow function named formatPrice that formats a total as rupees with two decimal places.
  4. Write void checkout(...) with a required onComplete callback. It should calculate and print the final total, then call the callback with a success message.
  5. Use a local variable or helper inside checkout to make the calculation easier to read.

Success condition: calling checkout with a list of prices and a discount prints a formatted total and then prints a completion message from the callback.

Flutter connection: in a Flutter app, the callback could update UI state, show a confirmation, or trigger navigation after the checkout logic completes.
Need a starting point? 
double calculateSubtotal(List<double> prices) {
  var total = 0.0;
  for (final price in prices) {
    total += price;
  }
  return total;
}

double applyDiscount({
  required double subtotal,
  double discountPercent = 0,
}) => subtotal - (subtotal * discountPercent / 100);
