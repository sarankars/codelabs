STEP 1 · START WITH THE PROBLEM

One App, Multiple Screens

Real apps rarely stay on one screen. Flutter's built-in Navigator manages movement between screens while keeping track of where the user came from.

By the end: Understand the navigation stack, use Navigator.push(), Navigator.pop(), MaterialPageRoute, pass constructor data forward, and return results back.

Core idea

Opening a new screen usually should not destroy the old one. Flutter keeps routes in a stack so the user can return.

STEP 7 · FIRST RUNNABLE APP

Complete Push/Pop Example

This is the smallest complete Navigator example students should be able to write confidently.

import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return const MaterialApp(
      debugShowCheckedModeBanner: false,
      home: HomePage(),
    );
  }
}

class HomePage extends StatelessWidget {
  const HomePage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Home'),
      ),
      body: Center(
        child: ElevatedButton(
          onPressed: () {
            Navigator.push(
              context,
              MaterialPageRoute(
                builder: (context) {
                  return const ProfilePage();
                },
              ),
            );
          },
          child: const Text('Open Profile'),
        ),
      ),
    );
  }
}

class ProfilePage extends StatelessWidget {
  const ProfilePage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Profile'),
      ),
      body: Center(
        child: ElevatedButton(
          onPressed: () {
            Navigator.pop(context);
          },
          child: const Text('Go Back'),

STEP 9 · SEND DATA FORWARD

Pass Data Through Constructor Parameters

A destination screen is still a widget, so constructor parameters are the simplest way to send data to it.

STEP 11 · SEND DATA BACK

Navigator.push() returns a Future that completes when the pushed route is later popped.

STEP 12 · RECEIVE THE RESULT

The source page can wait until the destination closes and then receive the returned result.

STEP 13 · TWO-WAY NAVIGATION

Select a Color and Return It

This complete example demonstrates pushing a page and returning a selected value.

import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return const MaterialApp(
      home: HomePage(),
    );
  }
}

class HomePage extends StatefulWidget {
  const HomePage({super.key});

  @override
  State<HomePage> createState() =>
      _HomePageState();
}

class _HomePageState
    extends State<HomePage> {

  String selectedColor = 'None';

  Future<void> chooseColor() async {
    final result =
        await Navigator.push<String>(
      context,
      MaterialPageRoute(
        builder: (context) {
          return const ColorSelectionPage();
        },
      ),
    );

    if (result == null) return;

    setState(() {
      selectedColor = result;
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Home'),
      ),
      body: Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            Text(
              'Selected: $selectedColor',
            ),
            ElevatedButton(
              onPressed: chooseColor,
              child: const Text(
                'Choose Color',
              ),
            ),
          ],
        ),
      ),
    );
  }
}

class ColorSelectionPage
    extends StatelessWidget {

  const ColorSelectionPage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Select Color'),
      ),
      body: Column(
        children: [
          ListTile(
            title: const Text('Blue'),
            onTap: () {
              Navigator.pop(
                context,
                'Blue',
              );
            },
          ),
          ListTile(
            title: const Text('Green'),
            onTap: () {
              Navigator.pop(
                context,
                'Green',
              );
            },
          ),
        ],
      ),
    );
  }
}

STEP 15 · STACK SAFETY

Check Whether You Can Pop

Flutter can tell you whether a Navigator has a route underneath the current route.

if (Navigator.canPop(context)) {
  Navigator.pop(context);
}
Interview point:

canPop() checks whether popping can reveal another route underneath.

STEP 16 · AVOID THESE

Common Navigator Mistakes

Most beginner mistakes come from confusing stack operations, context, or data direction.

Mistake 1Using global variables instead of constructor parameters for simple forward data.
Mistake 2Calling pop() expecting it to open a new screen.
Mistake 3Forgetting await when expecting a returned result.
Mistake 4Assuming the returned result can never be null.
Mistake 5Using pushReplacement() when Back should return to the previous page.
Simple rule:

push = add. pop = remove top. pushReplacement = replace current.

STEP 17 · CHECK YOUR UNDERSTANDING

Navigator Interview Revision

Students should be able to explain the stack first and the API second.

1. What is Navigator?
A widget that manages a stack of Route objects.
2. What is a Route?
A navigable entry/page managed by Navigator. MaterialPageRoute is a common route implementation.
3. What does push() do?
Adds a route to the top and returns a Future that completes when that route is popped.
4. What does pop() do?
Removes the top route and can optionally return a result.
5. Why does Navigator need BuildContext?
To find the appropriate Navigator relative to that widget's location.
6. How do you pass data forward?
Constructor parameters are a simple and clean approach.
7. How do you return data?
Call Navigator.pop(context, result) and await the original push.
8. Why can a returned result be null?
The page may close without returning a value.
9. push vs pushReplacement?
push keeps the current route underneath; pushReplacement replaces it.
10. What does canPop() check?
Whether popping can reveal another route below.

STEP 18 · PUT EVERYTHING TOGETHER

Student List → Details → Result

Open a details page, pass a Student object forward, then return a result back to the list page.

import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return const MaterialApp(
      debugShowCheckedModeBanner: false,
      home: StudentListPage(),
    );
  }
}

class Student {
  final int id;
  final String name;
  final int age;

  const Student({
    required this.id,
    required this.name,
    required this.age,
  });
}

class StudentListPage
    extends StatefulWidget {

  const StudentListPage({super.key});

  @override
  State<StudentListPage> createState() =>
      _StudentListPageState();
}

class _StudentListPageState
    extends State<StudentListPage> {

  final students = const [
    Student(id: 101, name: 'Aman', age: 21),
    Student(id: 102, name: 'Riya', age: 20),
    Student(id: 103, name: 'John', age: 22),
  ];

  String lastAction = 'No action yet';

  Future<void> openStudent(
    Student student,
  ) async {

    final result =
        await Navigator.push<String>(
      context,
      MaterialPageRoute(
        builder: (context) {
          return StudentDetailsPage(
            student: student,
          );
        },
      ),
    );

    if (result == null) return;

    setState(() {
      lastAction = result;
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Students'),
      ),
      body: Column(
        children: [
          Padding(
            padding: const EdgeInsets.all(16),
            child: Text(lastAction),
          ),
          Expanded(
            child: ListView.builder(
              itemCount: students.length,
              itemBuilder: (context, index) {
                final student = students[index];

                return ListTile(
                  title: Text(student.name),
                  subtitle: Text(
                    'Age: ${student.age}',
                  ),
                  trailing: const Icon(
                    Icons.chevron_right,
                  ),
                  onTap: () {
                    openStudent(student);
                  },
                );
              },
            ),
          ),
        ],
      ),
    );
  }
}

class StudentDetailsPage
    extends StatelessWidget {

  final Student student;

  const StudentDetailsPage({
    super.key,
    required this.student,
  });

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: Text(student.name),
      ),
      body: Padding(
        padding: const EdgeInsets.all(20),
        child: Column(
          crossAxisAlignment:
              CrossAxisAlignment.stretch,
          children: [
            Text(
              'Student ID: ${student.id}',
            ),
            const SizedBox(height: 8),
            Text(
              'Age: ${student.age}',
            ),
            const SizedBox(height: 24),
            ElevatedButton(
              onPressed: () {
                Navigator.pop(
                  context,
                  'Viewed ${student.name}',
                );
              },
              child: const Text(
                'Mark as Viewed & Go Back',
              ),
            ),
          ],
        ),
      ),
    );
  }
}
