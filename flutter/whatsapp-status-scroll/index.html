STEP 2 · AXES

Understand Horizontal Scrolling

ListView is vertical by default. Set scrollDirection: Axis.horizontal to lay out and move its children from side to side.

Axis.vertical

Item 1↓Item 2

The scroll extent grows from top to bottom.

Axis.horizontal

Item 1→Item 2

The scroll extent grows from left to right.

ListView(
  scrollDirection: Axis.horizontal,
  children: const [
    Text('Status 1'),
    Text('Status 2'),
    Text('Status 3'),
  ],
)
CONSTRAINT RULE

A horizontal ListView expands in its cross axis—the vertical direction. When it sits inside a Column, give it a finite height.

STEP 3 · VIEWPORT

Give the Status Rail a Height

SizedBox defines the 120-pixel-tall viewport through which the horizontal content will be visible.

Place this as the first child of the outer Column, before the message rows:

SizedBox(
  height: 120,
  child: ListView(
    scrollDirection: Axis.horizontal,
    children: const [
      SizedBox(width: 80, child: Center(child: Text('One'))),
      SizedBox(width: 80, child: Center(child: Text('Two'))),
      SizedBox(width: 80, child: Center(child: Text('Three'))),
    ],
  ),
),
SizedBox height

Bounds the ListView's cross axis so Flutter knows how tall its viewport is.

Child widths

Determine how much horizontal space each status entry occupies.

About shrinkWrap: Do not add shrinkWrap: true here. The ListView already receives finite width from the screen and finite height from the SizedBox. Shrink-wrapping the scrolling axis is unnecessary and requires extra measurement.
STEP 4 · REPEAT STORIES

Generate Ten Status Items

Use a collection for to insert ten padded status widgets into the horizontal list.

SizedBox(
  height: 120,
  child: ListView(
    scrollDirection: Axis.horizontal,
    children: [
      for (int i = 0; i < 10; i++)
        Padding(
          padding: const EdgeInsets.all(8),
          child: Column(
            children: const [
              CircleAvatar(radius: 30),
              SizedBox(height: 5),
              Text('Person', style: TextStyle(fontSize: 12)),
            ],
          ),
        ),
    ],
  ),
),
WidgetJob
PaddingCreates touch-friendly space around each status.
Inner ColumnPlaces the avatar above the first name.
CircleAvatarDisplays a circular profile image.
SizedBox(height: 5)Adds a predictable gap before the name.
WHY IT OVERFLOWS SIDEWAYS

Ten items are wider than the phone viewport. ListView keeps them in one horizontal sequence and lets the user reveal the off-screen items by dragging.

STEP 5 · STATUS RING

Style the Avatar Border

Wrap the avatar in a circular Container to create the green status ring.

Container(
  decoration: BoxDecoration(
    shape: BoxShape.circle,
    border: Border.all(
      color: Colors.green.shade600,
      width: 2,
    ),
  ),
  padding: const EdgeInsets.all(2),
  child: CircleAvatar(
    radius: 30,
    backgroundImage: NetworkImage(
      faker.image.loremPicsum(
        random: 0,
        seed: faker.randomGenerator.string(100),
      ),
    ),
  ),
),
BoxShape.circle

Makes the Container's decoration circular.

Border.all

Draws the green outline around the circle.

Padding

Creates a narrow gap between the ring and avatar.

NetworkImage

Loads the placeholder image URL generated by Faker.

Design experiment: Change the border to gray to represent a viewed status, or use a gradient decoration for an unread status style.
STEP 6 · LABELS

Add Generated First Names

Use a short first name beneath the avatar so every status remains compact.

Column(
  children: [
    // The circular status Container goes here.
    const SizedBox(height: 5),
    SizedBox(
      width: 68,
      child: Text(
        faker.person.firstName(),
        maxLines: 1,
        overflow: TextOverflow.ellipsis,
        textAlign: TextAlign.center,
        style: const TextStyle(fontSize: 12),
      ),
    ),
  ],
),
ROBUST LABEL

The supplied code displays the Text at its natural width. A small bounded width plus TextOverflow.ellipsis keeps longer generated names from changing the spacing between status items.

Generated data: Faker calls inside build can return new people when the widget rebuilds. This matches the exercise, but stable demo contacts should be generated once and stored in state.
STEP 7 · TWO SCROLLABLES

Combine Statuses and Messages

The outer SingleChildScrollView owns vertical movement. The inner ListView owns horizontal movement and has a bounded height.

SingleChildScrollView · vertical
└── Column
    ├── SizedBox(height: 120)
    │   └── ListView · horizontal
    │       └── 10 status items
    └── 100 message rows
GestureWidget that responds
Mostly horizontal drag over the status railThe inner horizontal ListView.
Vertical drag through the pageThe outer SingleChildScrollView.
body: SingleChildScrollView(
  child: Column(
    children: [
      SizedBox(
        height: 120,
        child: ListView(
          scrollDirection: Axis.horizontal,
          children: [
            for (int i = 0; i < 10; i++)
              buildStatusItem(),
          ],
        ),
      ),
      for (int i = 0; i < 100; i++)
        buildMessageItem(),
    ],
  ),
),
SAFE NESTING

Nested scrolling is simplest when the axes differ and the inner scrollable has a clear size. Two unbounded vertical scrollables would create constraint and gesture problems.

STEP 8 · COMPLETE VERSION

Run the Finished Screen

This complete learning version follows the supplied structure while removing the unused Cupertino import and unnecessary shrinkWrap.

import 'package:faker/faker.dart';
import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatefulWidget {
  const MyApp({super.key});

  @override
  State<MyApp> createState() => _MyAppState();
}

class _MyAppState extends State<MyApp> {
  final Faker faker = Faker();

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      home: Scaffold(
        appBar: AppBar(
          leading: const Icon(Icons.menu),
          titleSpacing: 0,
          title: const Text('Messenger'),
          centerTitle: false,
        ),
        body: SingleChildScrollView(
          child: Column(
            children: [
              SizedBox(
                height: 120,
                child: ListView(
                  scrollDirection: Axis.horizontal,
                  children: [
                    for (int i = 0; i < 10; i++)
                      Padding(
                        padding: const EdgeInsets.all(8),
                        child: Column(
                          children: [
                            Container(
                              decoration: BoxDecoration(
                                shape: BoxShape.circle,
                                border: Border.all(
                                  color: Colors.green.shade600,
                                  width: 2,
                                ),
                              ),
                              padding: const EdgeInsets.all(2),
                              child: CircleAvatar(
                                radius: 30,
                                backgroundImage: NetworkImage(
                                  faker.image.loremPicsum(
                                    random: 0,
                                    seed: faker.randomGenerator.string(100),
                                  ),
                                ),
                              ),
                            ),
                            const SizedBox(height: 5),
                            SizedBox(
                              width: 68,
                              child: Text(
                                faker.person.firstName(),
                                maxLines: 1,
                                overflow: TextOverflow.ellipsis,
                                textAlign: TextAlign.center,
                                style: const TextStyle(fontSize: 12),
                              ),
                            ),
                          ],
                        ),
                      ),
                  ],
                ),
              ),
              for (int i = 0; i < 100; i++)
                Column(
                  children: [
                    ListTile(
                      onTap: () {},
                      leading: CircleAvatar(
                        backgroundImage: NetworkImage(
                          faker.image.loremPicsum(
                            random: 0,
                            seed: faker.randomGenerator.string(100),
                          ),
                        ),
                      ),
                      title: Text(
                        faker.person.name(),
                        style: const TextStyle(fontWeight: FontWeight.bold),
                      ),
                      subtitle: Text(
                        faker.lorem.sentence(),
                        maxLines: 1,
                        overflow: TextOverflow.ellipsis,
                      ),
                    ),
                    const Divider(height: 0),
                  ],
                ),
            ],
          ),
        ),
      ),
    );
  }
}

Test the interaction

  1. Drag the status rail left and right without moving the page vertically.
  2. Drag upward to move the statuses and messages off screen together.
  3. Increase the statuses from 10 to 20.
  4. Test a narrow device and a landscape device.
STEP 9 · SCALE IT

Make Both Collections Lazy

Ten statuses are small, but the 100-message Column is eager. Use builders for the repeated children and a CustomScrollView when the status rail should scroll away with the message feed.

Lazy horizontal statuses

SizedBox(
  height: 120,
  child: ListView.builder(
    scrollDirection: Axis.horizontal,
    itemCount: statuses.length,
    itemBuilder: (context, index) {
      return StatusItem(status: statuses[index]);
    },
  ),
)

One lazy vertical scroll owner

body: CustomScrollView(
  slivers: [
    SliverToBoxAdapter(
      child: SizedBox(
        height: 120,
        child: ListView.builder(
          scrollDirection: Axis.horizontal,
          itemCount: statuses.length,
          itemBuilder: (context, index) {
            return StatusItem(status: statuses[index]);
          },
        ),
      ),
    ),
    SliverList.builder(
      itemCount: messages.length,
      itemBuilder: (context, index) {
        return Column(
          children: [
            MessageTile(message: messages[index]),
            const Divider(height: 0),
          ],
        );
      },
    ),
  ],
),
StructureBehavior
SingleChildScrollView + ColumnEasy to learn, but eagerly builds all 100 messages.
Column + status rail + Expanded(ListView.builder)Messages are lazy, but the status rail remains fixed above them.
CustomScrollView + SliverToBoxAdapter + SliverListStatus rail scrolls away with one lazy vertical message feed.
DATA FIRST

Load or generate stable status and message records once, then let each builder read the record at its index. Avoid generating a new person inside a lazy builder because rows may rebuild while scrolling.
