STEP 4 · jsonDecode()

Convert JSON Text into Dart Data

response.body is a String. jsonDecode() parses that text into Dart values.

import 'dart:convert';

final data = jsonDecode(response.body);
response.body
String containing JSON
↓ jsonDecode()
Dart Map / List / primitive values
Remember:

jsonDecode() does not automatically create your custom Product class. It only converts JSON text into normal Dart maps, lists, strings, numbers, booleans, and null.

STEP 5 · JSON OBJECT IN DART

Work with Map<String, dynamic>

A map stores key-value pairs. The key is a String, while the value can have different types.

final Map<String, dynamic> productJson = {
  'id': 1,
  'title': 'Laptop',
  'price': 799.99,
  'stock': 12,
};

print(productJson['title']);
print(productJson['price']);
Why dynamic?

One JSON object may contain a String, int, double, bool, List, another Map, or null. The value type therefore needs to allow multiple possibilities.

STEP 6 · JSON ARRAY IN DART

Work with List<dynamic>

A JSON array becomes a Dart List. For the products endpoint, each item in the list is a decoded product map.

final List<dynamic> products = data['products'];

STEP 7 · MODEL CLASS

Create a Product Class

A model represents the data your app works with using normal Dart fields and types.

Now Flutter gets types:

STEP 9 · PARSE ONE PRODUCT

Create Product.fromJson()

Read each field from the JSON map and pass it into the Product constructor.

factory Product.fromJson(
  Map<String, dynamic> json,
) {
  return Product(
    id: json['id'],
    title: json['title'],
    description: json['description'],
    category: json['category'],
    price: (json['price'] as num).toDouble(),
    rating: (json['rating'] as num).toDouble(),
    stock: json['stock'],
    thumbnail: json['thumbnail'],
  );
}
Why num then toDouble()?

JSON numbers may decode as either int or double. Reading through num and converting with toDouble() makes numeric parsing safer.

STEP 11 · PARSE MANY PRODUCTS

Turn the JSON Array into List<Product>

The API gives us many product maps. Use map() to convert each map with Product.fromJson().

final Map<String, dynamic> data =
    jsonDecode(response.body);

final List<dynamic> productList =
    data['products'];

final List<Product> products = productList
    .map(
      (json) => Product.fromJson(
        json as Map<String, dynamic>,
      ),
    )
    .toList();

STEP 15 · REAL API SAFETY

What If a Field Is Missing or null?

Real APIs are not always perfect. Some properties can be optional, missing, or explicitly null.

class Product {
  final int id;
  final String title;
  final String? brand;

  const Product({
    required this.id,
    required this.title,
    this.brand,
  });

  factory Product.fromJson(
    Map<String, dynamic> json,
  ) {
    return Product(
      id: json['id'],
      title: json['title'],
      brand: json['brand'] as String?,
    );
  }
}
String? means:

The field may contain a String or null.

STEP 16 · DEFAULT VALUES

Use Safe Fallbacks When Appropriate

If your app needs a non-null value even when the API omits a field, provide a sensible fallback.

factory Product.fromJson(
  Map<String, dynamic> json,
) {
  return Product(
    id: json['id'] as int? ?? 0,
    title: json['title'] as String? ?? 'Unknown Product',
    description:
        json['description'] as String? ?? '',
    category:
        json['category'] as String? ?? 'unknown',
    price:
        (json['price'] as num?)?.toDouble() ?? 0.0,
    rating:
        (json['rating'] as num?)?.toDouble() ?? 0.0,
    stock: json['stock'] as int? ?? 0,
    thumbnail:
        json['thumbnail'] as String? ?? '',
  );
}
IMPORTANT

Do not blindly hide bad server data with defaults. Use defaults when they make sense for your application. If a field is essential, you may prefer to treat missing data as an error.

Future<List<Product>> fetchProducts() async {
  final url = Uri.parse(
    'https://dummyjson.com/products?limit=10',
  );

  final response = await http.get(url);

  if (response.statusCode != 200) {
    throw Exception(
      'Failed to load products',

  final Map<String, dynamic> data =
      jsonDecode(response.body);

  final List<dynamic> items =
      data['products'];

  return items
      .map(
        (json) => Product.fromJson(
          json as Map<String, dynamic>,

STEP 20 · QUICK REVISION

JSON & Dart Models Revision

Review the concepts you should remember before moving to complete CRUD operations.

1. What does jsonDecode() do?
It parses JSON text and converts it into Dart values such as maps, lists, strings, numbers, booleans, and null.
2. What does a JSON object usually become in Dart?
Map<String, dynamic>.
3. What does a JSON array usually become in Dart?
List<dynamic>.
4. Why create a model class?
Models give API data meaningful fields, stronger typing, better autocomplete, and cleaner UI code.
5. What does fromJson() do?
It converts a decoded JSON map into an instance of your model class.
6. What does toJson() do?
It converts a model object into a Dart map that can later be encoded as JSON.
7. What does jsonEncode() do?
It converts compatible Dart data such as maps and lists into JSON text.
8. How do we convert many product maps?
Use map() with Product.fromJson(), then call toList().
9. What does String? mean?
The field is nullable: it may contain a String or null.
10. Why use (json['price'] as num?)?.toDouble()?
JSON numbers can decode as int or double. Reading them as num first lets us safely convert either representation into a double.
