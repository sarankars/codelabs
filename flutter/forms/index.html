STEP 2 · CHOOSE THE RIGHT INPUT

TextField vs TextFormField

You already know TextField. For structured forms, Flutter gives us TextFormField, which integrates with the Form validation system.

TextFormField

    }

    return null;
  },

TextField = collect text. TextFormField = collect text + participate in form validation.

STEP 3 · GROUP THE FIELDS

Wrap Related Inputs in Form

Form groups multiple form fields so Flutter can validate, save, or reset them as one unit.

Form

Important:

Form does not invent your validation rules. Each field defines its own validator, while the Form coordinates the fields.

STEP 5 · THE MOST IMPORTANT RULE

Validator Returns an Error or null

Every validator receives the current field value and decides whether that value is acceptable.

validator: (value) {
  if (value == null || value.isEmpty) {
    return 'Name is required';
  }

  return null;
},
return 'Error'❌ Invalid. Flutter displays the returned message.
return null✅ Valid. No validation error exists.

Memorize this

String = invalid. null = valid.

STEP 6 · WRITE REAL RULES

Validate Name, Email, and Password

A validator can have one rule or several. Return the first useful error message you find.

Name

validator: (value) {
  if (value == null ||
      value.trim().isEmpty) {
    return 'Please enter your name';
  }

  return null;
},

trim() removes extra spaces from the beginning and end, so a value containing only spaces is treated as empty.

Email

validator: (value) {
  if (value == null ||
      value.trim().isEmpty) {
    return 'Please enter your email';
  }

  if (!value.contains('@')) {
    return 'Please enter a valid email';
  }

  return null;
},
KEEP IT SIMPLE

This is intentionally a beginner-friendly email check. The goal of this codelab is learning Flutter validation, not building a giant regular expression.

Password

validator: (value) {
  if (value == null ||
      value.isEmpty) {
    return 'Please enter a password';
  }

  if (value.length < 8) {
    return 'Password must be at least 8 characters';
  }

  return null;
},
Password entered
↓
Empty? → error
↓ no
Less than 8 chars? → error
↓ no
return null → valid

STEP 8 · READ THE DATA

Use Controllers to Read Submitted Values

Validation tells us whether the data is acceptable. Controllers let us access the actual text entered by the user.

Attach one to a field

TextFormField(

Read the text

print(nameController.text);
print(emailController.text);
Different jobs:

STEP 9 · CONNECT TO LIFECYCLE

Dispose the Controllers

This is where the StatefulWidget lifecycle lesson becomes practical. The State owns these controllers, so clean them up when the State is permanently removed.

@override
void dispose() {
  nameController.dispose();
  emailController.dispose();
  passwordController.dispose();
  confirmPasswordController.dispose();

  super.dispose();
}

STEP 10 · FIELDS CAN WORK TOGETHER

Validate Confirm Password

Some rules depend on another field. Confirm-password validation is a perfect beginner example.

Password field

TextFormField(
  controller: passwordController,
  obscureText: true,
  validator: (value) {
    if (value == null || value.isEmpty) {
      return 'Please enter a password';
    }

    if (value.length < 8) {
      return 'Password must be at least 8 characters';
    }

    return null;
  },
)

Confirm password field

TextFormField(
  controller: confirmPasswordController,
  obscureText: true,
  validator: (value) {
    if (value == null || value.isEmpty) {
      return 'Please confirm your password';
    }

    if (value != passwordController.text) {
      return 'Passwords do not match';
    }

    return null;
  },
)
Why this works:

The confirm-password validator receives its own value and compares it with passwordController.text.

STEP 12 · START FRESH

Reset the Form

A Reset button lets the user clear the form and remove validation state.

void resetForm() {
  formKey.currentState?.reset();

  nameController.clear();
  emailController.clear();
  passwordController.clear();
  confirmPasswordController.clear();
}
OutlinedButton(
  onPressed: resetForm,
  child: const Text('Reset'),
)
FormState.reset()

Resets the state of the form fields, including validation state.

controller.clear()

Explicitly clears the text managed by that controller.

Beginner-friendly rule:

If you are using controllers and want a visibly empty form, clear them explicitly.

STEP 14 · BUILD THE REAL THING

Complete Student Registration Form

Now combine everything into one runnable application.

import 'package:flutter/material.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(
        colorSchemeSeed: Colors.blue,
        useMaterial3: true,
      ),
      home: const RegistrationPage(),
    );
  }
}

class RegistrationPage extends StatefulWidget {
  const RegistrationPage({super.key});

  @override
  State<RegistrationPage> createState() =>
      _RegistrationPageState();
}

class _RegistrationPageState
    extends State<RegistrationPage> {

  final formKey =
      GlobalKey<FormState>();

  final nameController =
      TextEditingController();

  final emailController =
      TextEditingController();

  final passwordController =
      TextEditingController();

  final confirmPasswordController =
      TextEditingController();

  void submitForm() {
    final isValid =
        formKey.currentState!.validate();

    if (!isValid) {
      return;
    }

    final name =
        nameController.text.trim();

    final email =
        emailController.text.trim();

    print('Name: $name');
    print('Email: $email');

    ScaffoldMessenger.of(context)
        .showSnackBar(
      SnackBar(
        content: Text(
          'Welcome, $name! Registration successful.',
        ),
      ),
    );
  }

  void resetForm() {
    formKey.currentState?.reset();

    nameController.clear();
    emailController.clear();
    passwordController.clear();
    confirmPasswordController.clear();
  }

  @override
  void dispose() {
    nameController.dispose();
    emailController.dispose();
    passwordController.dispose();
    confirmPasswordController.dispose();

    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text(
          'Student Registration',
        ),
      ),

      body: SafeArea(
        child: SingleChildScrollView(
          padding: const EdgeInsets.all(20),

          child: Form(
            key: formKey,

            autovalidateMode:
                AutovalidateMode
                    .onUserInteraction,

            child: Column(
              crossAxisAlignment:
                  CrossAxisAlignment.stretch,

              children: [
                TextFormField(
                  controller:
                      nameController,

                  textInputAction:
                      TextInputAction.next,

                  decoration:
                      const InputDecoration(
                    labelText: 'Name',
                    border:
                        OutlineInputBorder(),
                  ),

                  validator: (value) {
                    if (value == null ||
                        value.trim().isEmpty) {
                      return 'Please enter your name';
                    }

                    if (value.trim().length < 2) {
                      return 'Name is too short';
                    }

                    return null;
                  },
                ),

                const SizedBox(height: 16),

                TextFormField(
                  controller:
                      emailController,

                  keyboardType:
                      TextInputType
                          .emailAddress,

                  textInputAction:
                      TextInputAction.next,

                  decoration:
                      const InputDecoration(
                    labelText: 'Email',
                    border:
                        OutlineInputBorder(),
                  ),

                  validator: (value) {
                    if (value == null ||
                        value.trim().isEmpty) {
                      return 'Please enter your email';
                    }

                    if (!value.contains('@')) {
                      return 'Please enter a valid email';
                    }

                    return null;
                  },
                ),

                const SizedBox(height: 16),

                TextFormField(
                  controller:
                      passwordController,

                  obscureText: true,

                  textInputAction:
                      TextInputAction.next,

                  decoration:
                      const InputDecoration(
                    labelText: 'Password',
                    border:
                        OutlineInputBorder(),
                  ),

                  validator: (value) {
                    if (value == null ||
                        value.isEmpty) {
                      return 'Please enter a password';
                    }

                    if (value.length < 8) {
                      return 'Password must be at least 8 characters';
                    }

                    return null;
                  },
                ),

                const SizedBox(height: 16),

                TextFormField(
                  controller:
                      confirmPasswordController,

                  obscureText: true,

                  textInputAction:
                      TextInputAction.done,

                  decoration:
                      const InputDecoration(
                    labelText:
                        'Confirm Password',
                    border:
                        OutlineInputBorder(),
                  ),

                  validator: (value) {
                    if (value == null ||
                        value.isEmpty) {
                      return 'Please confirm your password';
                    }

                    if (value !=
                        passwordController.text) {
                      return 'Passwords do not match';
                    }

                    return null;
                  },
                ),

                const SizedBox(height: 24),

                Row(
                  children: [
                    Expanded(
                      child: OutlinedButton(
                        onPressed: resetForm,
                        child:
                            const Text('Reset'),
                      ),
                    ),

                    const SizedBox(width: 12),

                    Expanded(
                      child: ElevatedButton(
                        onPressed: submitForm,
                        child:
                            const Text('Register'),
                      ),
                    ),
                  ],
                ),
              ],
            ),
          ),
        ),
      ),
    );
  }
}

STEP 15 · CHECK YOUR UNDERSTANDING

Forms and Validation Interview Revision

Explain the idea in simple language first, then mention the Flutter API.

1. What is Form?
Form groups related form fields so they can be validated, saved, and reset together.
2. TextField vs TextFormField?
TextField is general text input. TextFormField participates in the Form system and has a validator.
3. Why GlobalKey<FormState>?
It lets us access the FormState associated with that specific Form and call methods such as validate() and reset().
4. What does a validator return?
A String means an error exists. null means the value is valid.
5. What does validate() do?
It runs the form fields' validators and returns true only when they all pass.
6. Why TextEditingController?
It gives access to the current text and lets us control or clear it.
7. Why dispose controllers?
The State owns those resources, so they should be cleaned up when the State is permanently removed.
8. How can one field validate against another?
Its validator can compare its value with another controller, such as comparing Confirm Password with passwordController.text.
9. What is AutovalidateMode.onUserInteraction?
It automatically validates after the user interacts with the field instead of showing errors immediately on the first frame.
10. Should submission happen before validation?
No. Validate first. If invalid, stop. Submit only when validation succeeds.
