STEP 2 · THE LAYOUT RULE

Constraints Go Down. Sizes Go Up.

A child cannot simply choose any size. Its parent first gives it an allowed size range, the child chooses a permitted size, and the parent decides where that child is placed.

The rule to remember

  1. Constraints go down: the parent sends minimum and maximum dimensions.
  2. Sizes go up: the child reports a size inside that range.
  3. The parent sets the position: the parent places the child in its own space.

Try three parent constraints

Child
100 × 70

The parent permits a range of sizes. The child can use its requested 100 × 70 size.

ConstraintMeaningTypical result
TightThe minimum and maximum are equal.The child must use that exact size.
LooseThe minimum is usually zero and a maximum is supplied.The child may choose a smaller permitted size.
BoundedA finite maximum exists.Fractional and maximum sizes have a clear limit.
UnboundedAn axis has no finite maximum.Some sizing widgets cannot calculate a useful result.

Why width can appear to be ignored

Scaffold(
  body: Container(
    width: 100,
    height: 100,
    color: Colors.blue,
  ),
)

The scaffold body can pass tight screen-sized constraints. The container must obey its parent even though it requests 100 × 100. Placing it inside Center gives it looser constraints, allowing the requested size.

Scaffold(
  body: Center(
    child: Container(
      width: 100,
      height: 100,
      color: Colors.blue,
    ),
  ),
)

STEP 3 · BOX HELPERS

Use Container When You Need Several Jobs

Container is convenient because it can combine sizing, spacing, alignment, decoration, and a child. When you need only one job, a smaller widget usually communicates your intent more clearly.

NeedPreferWhy
A background color onlyColoredBoxIts purpose is immediately clear.
A border, gradient, radius, or shadowDecoratedBoxIt focuses on painting a decoration.
A fixed size or empty gapSizedBoxIt expresses size without extra behavior.
Padding onlyPaddingIt makes the spacing visible in the widget tree.
Several box features togetherContainerCombining the features is convenient.

Container

Container(
  width: 280,
  height: 140,
  padding: const EdgeInsets.all(20),
  alignment: Alignment.bottomLeft,
  decoration: BoxDecoration(
    color: Colors.blue.shade100,
    borderRadius: BorderRadius.circular(16),
  ),
  child: const Text('Flutter Course'),
)
COMMON ERROR

Do not set both color and decoration on the same container. Put the color inside BoxDecoration when a decoration is present.

Specialized alternatives

const SizedBox(
  width: 240,
  height: 100,
  child: ColoredBox(
    color: Colors.amber,
    child: Center(child: Text('Color only')),
  ),
)
DecoratedBox(
  decoration: BoxDecoration(
    border: Border.all(width: 2),
    borderRadius: BorderRadius.circular(12),
  ),
  child: const Padding(
    padding: EdgeInsets.all(16),
    child: Text('Decoration only'),
  ),
)

STEP 4 · BREATHING ROOM

Padding Is Inside. Margin Is Outside.

Spacing communicates grouping and hierarchy. Flutter represents spacing with explicit boxes, so it helps to know exactly which boundary receives the empty space.

Pink: surrounding area
Yellow: margin outside
Blue: padding inside
Child
ConstructorUseExample
EdgeInsets.allSame value on every sideEdgeInsets.all(16)
EdgeInsets.symmetricHorizontal and vertical valuesEdgeInsets.symmetric(horizontal: 24, vertical: 12)
EdgeInsets.onlySelected sidesEdgeInsets.only(top: 8, left: 16)
EdgeInsets.fromLTRBDifferent value for every sideEdgeInsets.fromLTRB(16, 8, 24, 12)
EdgeInsetsDirectionalStart and end based on reading directionEdgeInsetsDirectional.only(start: 16)
Container(
  margin: const EdgeInsets.all(24),       // Outside
  color: Colors.blue.shade100,
  child: const Padding(
    padding: EdgeInsets.all(16),          // Inside
    child: Text('Course description'),
  ),
)

STEP 6 · SIZE RULES

Set Minimums, Maximums, and Fractions

ConstrainedBox adds size rules to those supplied by its parent. FractionallySizedBox chooses a fraction of the available bounded space.

Minimum and maximum sizes

ConstrainedBox(
  constraints: const BoxConstraints(
    minWidth: 120,
    minHeight: 48,
    maxWidth: 320,
  ),
  child: ElevatedButton(
    onPressed: () {},
    child: const Text('Continue'),
  ),
)
ConstructorPurpose
BoxConstraints(...)Specify minimum and maximum dimensions.
BoxConstraints.tight(Size(...))Require one exact width and height.
BoxConstraints.tightFor(...)Require an exact supplied width, height, or both.
BoxConstraints.expand()Fill all permitted space.
IMPORTANT

ConstrainedBox adds constraints; it does not erase the constraints from its parent. A maximum width cannot shrink a child when the parent already requires a larger exact width.

Use a fraction of available space

FractionallySizedBox(
  widthFactor: 0.8,
  child: Container(
    height: 80,
    color: Colors.blue,
    alignment: Alignment.center,
    child: const Text('80% of available width'),
  ),
)

A width factor of 0.8 means 80% of the available bounded width. The widget needs a finite maximum to calculate a useful fraction.

STEP 7 · PROPORTIONS

Preserve Shape and Scale Content

AspectRatio asks for a proportional box. FittedBox scales and positions its child inside the space it receives.

AspectRatio

AspectRatio(
  aspectRatio: 16 / 9,
  child: ColoredBox(
    color: Colors.blue,
    child: Center(child: Text('16:9 banner')),
  ),
)

FittedBox

const SizedBox(
  width: 240,
  height: 120,
  child: FittedBox(
    fit: BoxFit.contain,
    child: FlutterLogo(size: 200),
  ),
)

Compare BoxFit values

contain shows the whole child and may leave empty space.

FitBehavior
containShow all content without cropping.
coverFill the box and crop what does not fit.
fillFill width and height, possibly distorting content.
fitWidth / fitHeightFit one axis and allow the other to crop or leave space.
scaleDownKeep the original size unless it must shrink.

STEP 8 · VISUAL BOUNDARIES

Group, Clip, and Separate Content

Some common widgets make boundaries visible. A Card groups related content, clipping keeps children inside a shape, and dividers separate nearby sections.

Card: a Material surface

const Card(
  child: Padding(
    padding: EdgeInsets.all(16),
    child: Text('Flutter layout lesson'),
  ),
)

Rounded paint is not rounded clipping

A rounded decoration paints a rounded background, but a child such as an image can still draw outside that shape. Use clipping when the child must stay inside the boundary.

ClipRRect(
  borderRadius: BorderRadius.circular(16),
  child: Image.asset(
    'assets/course_banner.jpg',
    width: 320,
    height: 180,
    fit: BoxFit.cover,
  ),
)
CARD SHORTCUT

A Card can clip its child with clipBehavior: Clip.antiAlias. Use that when the card itself owns the rounded boundary.

Divider and VerticalDivider

const Divider(
  height: 24,
  thickness: 1,
  indent: 16,
  endIndent: 16,
)
const SizedBox(
  height: 48,
  child: VerticalDivider(
    width: 24,
    thickness: 1,
  ),
)

A vertical divider needs a bounded height. Later, you will normally place it between children in a horizontal layout.

STEP 9 · SCREEN EDGES

Keep Content Away from System UI

Phones can have status bars, camera cutouts, rounded corners, and gesture areas. SafeArea adds enough padding to keep important content visible.

Place it near the screen boundary

Usually wrap the main screen content instead of wrapping every small child.

Select protected sides

Disable a side only when the design intentionally handles that system area.

Scaffold(
  body: SafeArea(
    minimum: const EdgeInsets.all(16),
    child: Center(
      child: Text('Safe screen content'),
    ),
  ),
)
PropertyPurpose
left, top, right, bottomChoose which sides receive system-safe padding.
minimumKeep at least your chosen amount of padding even when system padding is smaller.
maintainBottomViewPaddingPreserve bottom view padding in specialized keyboard layouts.
DO NOT OVERUSE IT

Nested safe areas do not normally keep adding the same system padding, but wrapping every component still obscures the screen's layout intent. Prefer one clear screen-level boundary.

STEP 10 · RECOGNIZE, DON'T MEMORIZE

Specialized Constraint Tools

You will occasionally encounter widgets that remove limits, permit overflow, or measure children intrinsically. Know their purpose, but reach for them only when ordinary constraints cannot express the design.

WidgetWhat it doesCaution
LimitedBoxAdds a maximum size only when the incoming constraint is unbounded.It may appear to do nothing in a bounded parent.
UnconstrainedBoxLets its child avoid some incoming constraints.The child can overflow the available space.
OverflowBoxAllows a child to be larger than its parent.Overflow can cover or hide nearby content.
IntrinsicWidthSizes a child using its intrinsic width.It can require an extra layout pass.
IntrinsicHeightSizes a child using its intrinsic height.It can be expensive in deep trees or lists.
Practical rule: First try SizedBox, ConstrainedBox, normal parent constraints, or a better widget-tree structure. Use intrinsic and unconstrained widgets only when you can explain why the simpler choices do not work.

A deliberate UnconstrainedBox

UnconstrainedBox(
  child: Container(
    width: 200,
    height: 80,
    color: Colors.orange,
    alignment: Alignment.center,
    child: const Text('I choose my requested size'),
  ),
)

STEP 11 · PUT IT TOGETHER

Build a Course Spotlight Card

Combine the everyday sizing and spacing widgets in one screen. Every wrapper should have one clear responsibility.

Scaffold
└── SafeArea: protect screen edges
    └── Center: position the card
        └── ConstrainedBox: maximum width
            └── FractionallySizedBox: use available width
                └── AspectRatio: preserve 16:9
                    └── Card: Material surface
                        └── Padding → Align → FittedBox → Text

One complete solution

import 'package:flutter/material.dart';

void main() {
  runApp(const CourseApp());
}

class CourseApp extends StatelessWidget {
  const CourseApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      home: Scaffold(
        backgroundColor: const Color(0xFFF1F4FF),
        body: SafeArea(
          minimum: const EdgeInsets.all(16),
          child: Center(
            child: ConstrainedBox(
              constraints: const BoxConstraints(maxWidth: 420),
              child: FractionallySizedBox(
                widthFactor: 1,
                child: AspectRatio(
                  aspectRatio: 16 / 9,
                  child: Card(
                    clipBehavior: Clip.antiAlias,
                    child: ColoredBox(
                      color: const Color(0xFF2856D8),
                      child: Padding(
                        padding: const EdgeInsets.all(24),
                        child: Align(
                          alignment: Alignment.bottomLeft,
                          child: FittedBox(
                            fit: BoxFit.scaleDown,
                            alignment: Alignment.centerLeft,
                            child: Text(
                              'Flutter UI\nSizing & Spacing',
                              style: TextStyle(
                                color: Colors.white,
                                fontSize: 34,
                                fontWeight: FontWeight.bold,
                                height: 1,
                              ),
                            ),
                          ),
                        ),
                      ),
                    ),
                  ),
                ),
              ),
            ),
          ),
        ),
      ),
    );
  }
}
