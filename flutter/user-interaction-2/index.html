STEP 2 · SINGLE CHOICE

Use Radio for one choice from a set

A radio group represents a single selected value. Each option compares itself with the current group value and reports a new selection through a callback.

String gender = 'Male';

Radio<String>(
  value: 'Male',
  groupValue: gender,
  onChanged: (value) {
    setState(() {
      gender = value!;
    });
  },
)
value identifies this option. groupValue holds the currently selected option.

STEP 3 · COMPACT CHOICES

Use a dropdown when choices should stay compact

Dropdown controls follow the same controlled-value pattern: provide the current value, provide items, and update state when onChanged returns a new selection.

String technology = 'Flutter';

DropdownButton<String>(
  value: technology,
  items: const [
    DropdownMenuItem(
      value: 'Flutter',
      child: Text('Flutter'),
    ),
    DropdownMenuItem(
      value: 'React',
      child: Text('React'),
    ),
    DropdownMenuItem(
      value: 'Spring Boot',
      child: Text('Spring Boot'),
    ),
  ],
  onChanged: (value) {
    setState(() {
      technology = value!;
    });
  },
)

STEP 4 · CONTINUOUS VALUES

Let the user choose a value from a range

Slider handles one numeric value. RangeSlider handles a lower and upper value together.

double experience = 2;

Slider(
  value: experience,
  min: 0,
  max: 5,
  divisions: 5,
  label: experience.round().toString(),
  onChanged: (value) {
    setState(() {
      experience = value;
    });
  },
)
RangeValues budget = const RangeValues(1000, 5000);

RangeSlider(
  values: budget,
  min: 0,
  max: 10000,
  onChanged: (values) {
    setState(() {
      budget = values;
    });
  },
)
Slider

One current value.

RangeSlider

Two values: start and end.

STEP 5 · EXPLORE GESTURES

Go beyond a simple tap

You already know onTap, onDoubleTap, and onLongPress. Now explore callbacks that expose more gesture detail.

GestureDetector(
  onTapDown: (details) {
    print(details.localPosition);
  },
  onTapUp: (details) {
    print('Tap released');
  },
  onPanUpdate: (details) {
    print(details.delta);
  },
  child: Container(
    width: 200,
    height: 200,
    color: Colors.blue,
  ),
)

onTapDown

Runs when a pointer begins a tap interaction and can provide position details.

onPanUpdate

Runs repeatedly while a drag/pan is moving and provides movement deltas.

STEP 7 · BLOCKING DECISIONS

Ask before destructive or important actions

showDialog() displays a modal route. An AlertDialog is ideal for confirmations that require a clear choice before continuing.

showDialog(
  context: context,
  builder: (context) {
    return AlertDialog(
      title: const Text('Delete item?'),
      content: const Text(
        'This action cannot be undone.',
      ),
      actions: [
        TextButton(
          onPressed: () {
            Navigator.pop(context);
          },
          child: const Text('Cancel'),
        ),
        TextButton(
          onPressed: () {
            // Delete item
            Navigator.pop(context);
          },
          child: const Text('Delete'),
        ),
      ],
    );
  },
);

STEP 8 · ACTION SHEETS

STEP 9 · SWIPE ACTIONS

Let list items respond to swipe gestures

Dismissible wraps a child and reports when the user dismisses it. Your underlying data must also be updated, otherwise the item can reappear after a rebuild.

Dismissible(
  key: ValueKey(tasks[index]),
  onDismissed: (direction) {
    setState(() {
      tasks.removeAt(index);
    });
  },
  background: Container(
    color: Colors.red,
    alignment: Alignment.centerRight,
    padding: const EdgeInsets.only(right: 20),
    child: const Icon(
      Icons.delete,
      color: Colors.white,
    ),
  ),
  child: ListTile(
    title: Text(tasks[index]),
  ),
)
A stable key helps Flutter identify which list item is being dismissed.

STEP 10 · INPUT FLOW

Control where the keyboard focus goes

FocusNode and TextInputAction help forms feel intentional: Next moves to the next field, Done can close the keyboard, and your code can request or release focus.

final emailFocus = FocusNode();

TextField(
  textInputAction: TextInputAction.next,
  onSubmitted: (_) {
    FocusScope.of(context).requestFocus(
      emailFocus,
    );
  },
),

TextField(
  focusNode: emailFocus,
  textInputAction: TextInputAction.done,
  onSubmitted: (_) {
    FocusScope.of(context).unfocus();
  },
)
