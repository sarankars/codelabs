STEP 2 · TYPOGRAPHY

TextStyle Controls More Than Font Size

Typography creates hierarchy. A title, subtitle, label, and body paragraph should not all shout with the same visual weight.

Change the headline

Flutter Styling

fontSize: 40, fontWeight: w700, color: blue

Text(
  'Build Better Interfaces',
  style: TextStyle(
    fontSize: 28,
    fontWeight: FontWeight.w700,
    color: Colors.indigo,
    height: 1.2,
    letterSpacing: -0.4,
  ),
)
PropertyUse it for
fontSizeVisual size of the text.
fontWeightEmphasis, from thin to bold.
colorForeground text color.
heightLine-height multiplier.
letterSpacingSpace between letters.
decorationUnderline, overline, or line-through.
GOOD PRACTICE

Use only a few intentional text roles. If every label has a different size, weight, and color, the screen becomes visually noisy.

STEP 4 · BOX DECORATION

Build a Surface with BoxDecoration

BoxDecoration groups visual properties that paint behind or around a child: background color, border, border radius, gradient, image, and shadow.

Compare surface styles

Course Spotlight

A single surface can combine shape, color, border, and shadow.

White surface, square corners, no extra border.

Container(
  padding: const EdgeInsets.all(20),
  decoration: BoxDecoration(
    color: Colors.white,
    borderRadius: BorderRadius.circular(16),
    border: Border.all(
      color: Colors.indigo,
      width: 2,
    ),
  ),
  child: const Text('Styled surface'),
)
COMMON ERROR

When a Container has a decoration, place the background color inside BoxDecoration instead of also setting the container's color property.

PropertyPurpose
colorSolid background color.
borderOutline around the box.
borderRadiusRounded corners.
gradientBlend multiple colors.
boxShadowPaint one or more shadows.

STEP 6 · DEPTH

Use Shadows as a Hierarchy Cue

BoxShadow can suggest elevation and separation. Small, soft shadows usually read more naturally than large dark shadows on every component.

decoration: BoxDecoration(
  color: Colors.white,
  borderRadius: BorderRadius.circular(16),
  boxShadow: const [
    BoxShadow(
      color: Color(0x22000000),
      blurRadius: 16,
      offset: Offset(0, 8),
    ),
  ],
)
PropertyMeaning
colorShadow color and opacity.
blurRadiusHow soft the shadow becomes.
spreadRadiusHow much the shadow expands before blurring.
offsetHorizontal and vertical displacement.
Small offset

Feels close to the surface.

Large blur

Feels softer and more diffused.

Low opacity

Keeps depth subtle instead of muddy.

DON'T OVERSTYLE

Border + gradient + multiple shadows + bright color + large radius on every component usually reduces hierarchy. Decide what deserves emphasis.

STEP 7 · BUTTONS

Style Buttons Without Rebuilding Them

Flutter's Material buttons already understand interaction. Prefer their styling APIs instead of replacing them with a plain Container and manually recreating button behavior.

Fast styling with styleFrom

ElevatedButton(
  style: ElevatedButton.styleFrom(
    backgroundColor: Colors.indigo,
    foregroundColor: Colors.white,
    padding: const EdgeInsets.symmetric(
      horizontal: 24,
      vertical: 14,
    ),
    shape: RoundedRectangleBorder(
      borderRadius: BorderRadius.circular(12),
    ),
    textStyle: const TextStyle(
      fontSize: 16,
      fontWeight: FontWeight.w700,
    ),
  ),
  onPressed: () {},
  child: const Text('Enroll now'),
)
ElevatedButton

Primary action with an elevated Material surface.

FilledButton

Strong Material 3 filled action.

OutlinedButton

Lower emphasis with a visible border.

Remember: backgroundColor styles the button surface; foregroundColor controls foreground content such as text and icons.
INTERACTION STATES

For advanced pressed, hovered, focused, or disabled styling, use a full ButtonStyle with state-aware properties. Keep the first version simple unless the design actually needs custom states.

STEP 8 · INPUT DECORATION

Make Form Fields Clear Before Making Them Fancy

InputDecoration controls the visual structure around a TextField or TextFormField: labels, hints, helper text, icons, fills, and borders.

Preview field states

Email address
student@example.com

Use a clear label and predictable border.

TextField(
  decoration: InputDecoration(
    labelText: 'Email address',
    hintText: 'student@example.com',
    prefixIcon: const Icon(Icons.email_outlined),
    filled: true,
    fillColor: const Color(0xFFF5F7FB),
    border: OutlineInputBorder(
      borderRadius: BorderRadius.circular(12),
    ),
    focusedBorder: OutlineInputBorder(
      borderRadius: BorderRadius.circular(12),
      borderSide: const BorderSide(
        color: Colors.indigo,
        width: 2,
      ),
    ),
  ),
)
PropertyPurpose
labelTextIdentifies what the field represents.
hintTextShows an example or temporary prompt.
prefixIconPlaces an icon before the editable text.
filled / fillColorPaints the field's interior.
borderDefault border shape.
focusedBorderBorder shown while the field has focus.
errorTextDisplays an error message under the field.

STEP 9 · MAINTAINABILITY

Don't Hide the UI Inside Magic Numbers

Readable styling makes future changes safer. A developer should be able to tell which values are intentional design decisions and which values belong only to one component.

Problem: repeated unexplained values

Container(
  padding: const EdgeInsets.all(18),
  decoration: BoxDecoration(
    color: const Color(0xFF2856D8),
    borderRadius: BorderRadius.circular(14),
  ),
  child: const Text(
    'Enroll',
    style: TextStyle(
      color: Colors.white,
      fontSize: 16,
      fontWeight: FontWeight.w700,
    ),
  ),
)

This is not automatically bad. A one-off component can contain local values. The problem starts when the same values are copied across many files without a shared meaning.

Better: name repeated design decisions

class AppStyles {
  static const brandBlue = Color(0xFF2856D8);
  static const cardRadius = 16.0;
  static const sectionGap = 24.0;

  static const title = TextStyle(
    fontSize: 28,
    fontWeight: FontWeight.w700,
    height: 1.2,
  );
}
Keep local values local

If a value belongs to one widget only, keeping it nearby may be clearest.

Extract repeated decisions

If a value represents your visual system, give it one source of truth.

IMPORTANT

Do not create a giant constants file just to avoid every number. The goal is meaningful reuse, not moving all values somewhere else.

STEP 10 · PUT IT TOGETHER

Build a Course Enrollment Card

Combine the styling tools into one component. Keep each choice purposeful: type for hierarchy, color for emphasis, decoration for grouping, and controls for action.

CourseEnrollmentCard
├── Container: gradient + radius + shadow
│   └── Padding
│       └── Column
│           ├── Text: label style
│           ├── Text: title style
│           ├── Text: body style
│           ├── TextField: InputDecoration
│           └── FilledButton: ButtonStyle

One complete solution

import 'package:flutter/material.dart';

void main() {
  runApp(const StylingApp());
}

class StylingApp extends StatelessWidget {
  const StylingApp({super.key});

  static const brandBlue = Color(0xFF2856D8);
  static const brandPurple = Color(0xFF7C4DFF);

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      home: Scaffold(
        backgroundColor: const Color(0xFFF5F7FB),
        body: Center(
          child: ConstrainedBox(
            constraints: const BoxConstraints(maxWidth: 440),
            child: Container(
              margin: const EdgeInsets.all(20),
              padding: const EdgeInsets.all(24),
              decoration: BoxDecoration(
                gradient: const LinearGradient(
                  begin: Alignment.topLeft,
                  end: Alignment.bottomRight,
                  colors: [brandBlue, brandPurple],
                ),
                borderRadius: BorderRadius.circular(20),
                boxShadow: const [
                  BoxShadow(
                    color: Color(0x33000000),
                    blurRadius: 18,
                    offset: Offset(0, 10),
                  ),
                ],
              ),
              child: Column(
                mainAxisSize: MainAxisSize.min,
                crossAxisAlignment: CrossAxisAlignment.start,
                children: [
                  const Text(
                    'FLUTTER UI',
                    style: TextStyle(
                      color: Color(0xFFFFD83D),
                      fontSize: 13,
                      fontWeight: FontWeight.w800,
                      letterSpacing: 1.2,
                    ),
                  ),
                  const SizedBox(height: 10),
                  const Text(
                    'Build Better Interfaces',
                    style: TextStyle(
                      color: Colors.white,
                      fontSize: 30,
                      fontWeight: FontWeight.w700,
                      height: 1.1,
                    ),
                  ),
                  const SizedBox(height: 10),
                  const Text(
                    'Practice typography, surfaces, controls, and readable styling.',
                    style: TextStyle(
                      color: Color(0xFFE7E9FF),
                      fontSize: 15,
                      height: 1.5,
                    ),
                  ),
                  const SizedBox(height: 22),
                  TextField(
                    decoration: InputDecoration(
                      hintText: 'Enter your email',
                      prefixIcon: const Icon(Icons.email_outlined),
                      filled: true,
                      fillColor: Colors.white,
                      border: OutlineInputBorder(
                        borderRadius: BorderRadius.circular(12),
                        borderSide: BorderSide.none,
                      ),
                    ),
                  ),
                  const SizedBox(height: 14),
                  SizedBox(
                    width: double.infinity,
                    child: FilledButton(
                      style: FilledButton.styleFrom(
                        backgroundColor: const Color(0xFFFFD83D),
                        foregroundColor: const Color(0xFF101010),
                        padding: const EdgeInsets.symmetric(vertical: 14),
                        shape: RoundedRectangleBorder(
                          borderRadius: BorderRadius.circular(12),
                        ),
                        textStyle: const TextStyle(
                          fontSize: 16,
                          fontWeight: FontWeight.w800,
                        ),
                      ),
                      onPressed: () {},
                      child: const Text('Enroll now'),
                    ),
                  ),
                ],
              ),
            ),
          ),
        ),
      ),
    );
  }
}

Your version

  1. Replace the gradient with a solid surface and add a 2-pixel border.
  2. Create three distinct text roles: eyebrow label, title, and body.
  3. Change the button from FilledButton to OutlinedButton while keeping it readable.
  4. Add a focused border to the email field.
  5. Move at least two repeated style values into named constants.
  6. Remove the shadow and decide whether the visual hierarchy is still clear.
