STEP 3 · PROGRAM 7

What Does Texture Extraction Mean?

Texture tells us whether an area looks smooth, rough, repetitive, irregular, or strongly patterned.

Image pixels
↓
Look at neighboring gray values
↓
Build a GLCM
↓
Calculate texture features
Contrast

How strongly neighboring pixels differ.

Homogeneity

How similar neighboring pixels are.

Energy

How uniform or orderly the texture is.

Correlation

How strongly neighboring gray levels are related.

Easy memory:

We are converting the visual texture of an image into a few numerical values.

STEP 4 · LOAD THE IMAGE

Read the Image in Grayscale

A GLCM works with gray-level values, so the easiest approach is to load the image directly as grayscale.

import cv2
from skimage.feature import graycomatrix, graycoprops

image = cv2.imread("texture.jpg", cv2.IMREAD_GRAYSCALE)
Line Very simple meaning
import cv2 Loads OpenCV so we can work with images.
from skimage.feature ... Imports the two functions we need for GLCM and texture features.
cv2.imread(...) Reads the image from the computer.
cv2.IMREAD_GRAYSCALE Loads it as one-channel grayscale instead of BGR color.
CHECKPOINT

If image becomes None, the file name or path is wrong.

STEP 5 · BUILD THE MATRIX

Create the Gray-Level Co-occurrence Matrix

The GLCM counts how often one grayscale value appears next to another grayscale value.

glcm = graycomatrix(
    image,
    distances=[1],
    angles=[0],
    levels=256,
    symmetric=True,
    normed=True
)
Part Meaning
image The grayscale image whose texture we want to study.
distances=[1] Compare each pixel with a neighbor one pixel away.
angles=[0] Look at the neighbor to the right.
levels=256 Grayscale has values from 0 to 255, so there are 256 possible levels.
symmetric=True Treat A-next-to-B and B-next-to-A as the same kind of relationship.
normed=True Convert raw counts into normalized values so the matrix is easier to use.
You do not need to print the whole GLCM.

It can be very large. Our goal is to extract useful numbers from it.

STEP 6 · EXTRACT FEATURES

Calculate the Texture Values

graycoprops() reads the GLCM and calculates useful texture properties.

contrast = graycoprops(glcm, "contrast")[0, 0]
homogeneity = graycoprops(glcm, "homogeneity")[0, 0]
energy = graycoprops(glcm, "energy")[0, 0]
correlation = graycoprops(glcm, "correlation")[0, 0]

print("Contrast:", contrast)
print("Homogeneity:", homogeneity)
print("Energy:", energy)
print("Correlation:", correlation)
Line Meaning
graycoprops(glcm, "contrast") Calculates how different neighboring gray values are.
[0, 0] We used one distance and one angle, so we take the first result.
"homogeneity" Measures neighbor similarity.
"energy" Measures texture uniformity/order.
"correlation" Measures the relationship between neighboring gray levels.
print(...) Shows the calculated values in the terminal.

STEP 7 · COMPLETE PROGRAM

Program 7: Texture Extraction

Here is the complete practical in one file.

import cv2
from skimage.feature import graycomatrix, graycoprops

image = cv2.imread("texture.jpg", cv2.IMREAD_GRAYSCALE)

if image is None:
    print("Image not found")
    exit()

glcm = graycomatrix(
    image,
    distances=[1],
    angles=[0],
    levels=256,
    symmetric=True,
    normed=True
)

contrast = graycoprops(glcm, "contrast")[0, 0]
homogeneity = graycoprops(glcm, "homogeneity")[0, 0]
energy = graycoprops(glcm, "energy")[0, 0]
correlation = graycoprops(glcm, "correlation")[0, 0]

print("Contrast:", contrast)
print("Homogeneity:", homogeneity)
print("Energy:", energy)
print("Correlation:", correlation)

cv2.imshow("Texture Image", image)
cv2.waitKey(0)
cv2.destroyAllWindows()
What happens when you run it?

The image opens in a window, and the terminal displays four numerical texture features.

STEP 11 · CREATE DETECTOR

Create the HOG Pedestrian Detector

HOG stands for Histogram of Oriented Gradients. It describes edge and shape patterns, which are useful for recognizing the shape of a person.

hog = cv2.HOGDescriptor()
hog.setSVMDetector(
    cv2.HOGDescriptor_getDefaultPeopleDetector()
)
Line Very simple meaning
cv2.HOGDescriptor() Creates an object that can calculate and use HOG features.
getDefaultPeopleDetector() Gets OpenCV's already-trained detector for human pedestrians.
setSVMDetector(...) Attaches that trained people detector to our HOG object.
Easy memory:

HOGDescriptor() creates the detector machinery. getDefaultPeopleDetector() gives it knowledge of what a pedestrian looks like.

STEP 12 · RUN DETECTION

Find People with detectMultiScale()

A pedestrian can appear at different sizes in an image, so OpenCV scans the image at multiple scales.

boxes, weights = hog.detectMultiScale(
    image,
    winStride=(8, 8),
    padding=(8, 8),
    scale=1.05
)
Part Meaning
detectMultiScale() Searches the image for pedestrians at different sizes.
image The image to search.
winStride=(8, 8) Moves the detection window across the image in small steps.
padding=(8, 8) Adds a small extra area around scanning windows.
scale=1.05 Checks the image at gradually changing sizes.
boxes Contains the position and size of every detected person.
weights Contains confidence-like scores returned by the detector.
IMPORTANT

Each item in boxes contains four numbers: x, y, w, h.

STEP 13 · SHOW RESULTS

Draw a Rectangle Around Every Person

The detector gives us coordinates. Now we turn those coordinates into visible bounding boxes.

for (x, y, w, h) in boxes:
    cv2.rectangle(
        image,
        (x, y),
        (x + w, y + h),
        (0, 255, 0),
        2
    )
Part Meaning
for ... in boxes Repeat once for every detected pedestrian.
x, y Top-left position of the detected box.
w, h Width and height of the detected box.
(x, y) Top-left corner of the rectangle.
(x + w, y + h) Bottom-right corner.
(0, 255, 0) Green color in OpenCV BGR format.

STEP 14 · COMPLETE PROGRAM

Program 8: Pedestrian Detection

Now combine every step into one working OpenCV program.

import cv2

image = cv2.imread("pedestrians.jpg")

if image is None:
    print("Image not found")
    exit()

hog = cv2.HOGDescriptor()
hog.setSVMDetector(
    cv2.HOGDescriptor_getDefaultPeopleDetector()
)

boxes, weights = hog.detectMultiScale(
    image,
    winStride=(8, 8),
    padding=(8, 8),
    scale=1.05
)

for (x, y, w, h) in boxes:
    cv2.rectangle(
        image,
        (x, y),
        (x + w, y + h),
        (0, 255, 0),
        2
    )

print("Pedestrians detected:", len(boxes))

cv2.imshow("Pedestrian Detection", image)
cv2.waitKey(0)
cv2.destroyAllWindows()
Expected result:

The output window shows the original image with green rectangles around detected pedestrians. The terminal prints how many detections were returned.
