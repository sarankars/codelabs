STEP 2 · FOUNDATION

What Does “Dimension” Mean?

In machine learning, each feature usually represents one dimension of the feature space.

A tiny image example

Consider a grayscale image of size 3 × 3:

10  12  11
50  52  51
90  91  92

If we flatten it into a feature vector:

X = [10, 12, 11, 50, 52, 51, 90, 91, 92]

There are 9 values, therefore this simple representation has 9 dimensions.

100 × 100 grayscale image

10,000 pixel features → 10,000 dimensions.

1920 × 1080 RGB image

More than 6 million channel values if every pixel channel is used directly.

Key idea

More features means a higher-dimensional feature space.

STEP 3 · PROBLEM

Curse of Dimensionality

As the number of dimensions increases, data becomes harder to represent, learn from, compare, and visualize.

Why is it called a “curse”?

Imagine dividing every dimension into only 10 possible regions.

DimensionsPossible regions
1D10
2D10² = 100
3D10³ = 1,000
10D10¹⁰ = 10,000,000,000
Result

The space grows extremely quickly, but the number of training samples usually does not. The data therefore becomes sparse.

Main problems

Sparse data

Samples occupy only a tiny portion of the huge feature space.

More computation

More values must be stored, processed, compared, and learned.

Overfitting

A model can learn accidental patterns when the number of features is large compared with the number of samples.

Distance problems

In very high dimensions, distances can become less useful for distinguishing samples.

What is one major effect of increasing dimensionality?

STEP 4 · SOLUTION

Feature Reduction

Feature reduction means representing the data using fewer features while trying to preserve the information that matters.

Original feature vector
[x₁, x₂, x₃, x₄, x₅, ... x₁₀₀₀₀]
↓ feature reduction
[z₁, z₂, z₃, ... z₁₀₀]

Why can features be reduced?

Many features may be redundant, correlated, noisy, or unimportant.

Simple example

If a dataset stores a person's height in centimeters, meters, and millimeters, those three columns mostly represent the same underlying information.

Two common approaches

Feature Selection

Keep some of the original features and remove others.

x1 x2 x3 x4 x5
↓
x1    x3    x5
Feature Extraction

Create new features by transforming or combining the original features.

x1 x2 x3 x4 x5
↓ transform
z1 z2
REMEMBER

Selection chooses old features. Extraction creates new features. PCA, LDA, and ICA are mainly feature-extraction techniques.

STEP 5 · PCA

Principal Component Analysis

PCA finds new directions in the data where the samples vary the most.

PCA asks:

“Which directions contain the largest amount of variation in my data?”

Imagine height and weight

Weight ↑

80 |                 ●
75 |              ●
70 |           ●
65 |        ●
60 |     ●
   +--------------------------→ Height

Height and weight are correlated. Most of the variation lies along one diagonal direction.

Original axes: Height + Weight
↓ PCA finds a new direction
PC1 = direction of maximum variance
↓
Project points onto PC1
↓
2 dimensions → possibly 1 useful dimension
Principal component

A principal component is a new feature formed as a weighted combination of the original features.

STEP 6 · PCA WORKFLOW

How PCA Works

PCA centers the data, measures how features vary together, finds important directions, and projects the data onto those directions.

Step 1 — Center the data

X_centered = X - mean(X)

The mean is moved to approximately zero so PCA focuses on variation around the center.

Step 2 — Compute covariance

covariance_matrix = covariance(X_centered)

Covariance tells us how features change together.

Step 3 — Find eigenvectors and eigenvalues

TermIntuition
EigenvectorWhich direction?
EigenvalueHow much variance exists in that direction?

Step 4 — Sort and keep the strongest components

PC1 → largest eigenvalue
PC2 → second largest eigenvalue
PC3 → third largest eigenvalue
...

Step 5 — Project the original data

High-dimensional X
↓ choose top principal components
Projection
↓
Lower-dimensional Z
STEP 7 · PCA INFORMATION

Explained Variance

Explained variance tells us how much of the dataset's variation is captured by each principal component.

If the eigenvalues correspond to:

ComponentExplained variance
PC170%
PC220%
PC37%
PC43%

Then the first two components preserve:

PC1 + PC2 = 90%

We can reduce 4 dimensions to 2 dimensions while keeping about 90% of the variance.

explained_variance_ratio = eigenvalue_i / sum(all_eigenvalues)

STEP 8 · PRACTICAL

PCA with Python

Use scikit-learn to reduce a simple four-feature dataset to two principal components.

import numpy as np
from sklearn.decomposition import PCA

X = np.array([
    [2.5, 2.4, 1.2, 0.8],
    [0.5, 0.7, 0.3, 0.2],
    [2.2, 2.9, 1.1, 0.9],
    [1.9, 2.2, 0.9, 0.7],
    [3.1, 3.0, 1.5, 1.0],
    [2.3, 2.7, 1.0, 0.8]
])

pca = PCA(n_components=2)
X_reduced = pca.fit_transform(X)

print("Original shape:", X.shape)
print("Reduced shape:", X_reduced.shape)
print("Explained variance:", pca.explained_variance_ratio_)
6 samples × 4 features
↓ PCA(n_components=2)
6 samples × 2 principal components

Important methods

CodeMeaning
PCA(n_components=2)Keep two principal components.
fit_transform(X)Learn the PCA directions and transform the data.
explained_variance_ratio_Shows how much variance each component preserves.
STEP 9 · COMPUTER VISION

PCA for Images and Eigenfaces

An image can be flattened into a long vector, and PCA can compress that vector into a much smaller set of components.

100 × 100 face image
↓ flatten
10,000 pixel features
↓ PCA
100 principal components
↓
Compact face representation

Eigenfaces

When PCA is applied to a collection of face images, the principal directions can be visualized as face-like patterns often called eigenfaces.

Uses

Historically, eigenfaces were used for face representation and recognition. PCA can also be useful for image compression, visualization, noise reduction, and preprocessing.

LIMITATION

PCA does not use class labels. It only cares about variance. The direction with maximum variance is not always the direction that best separates classes.

STEP 10 · LDA

Linear Discriminant Analysis

LDA finds directions that make different classes easier to separate.

LDA asks:

“Which direction separates my known classes the best?”

Suppose the data has two labeled classes:

Class A: ● ● ● ●

                         ○ ○ ○ ○ : Class B

LDA looks for a projection where:

● ● ● ●                  ○ ○ ○ ○

compact Class A      compact Class B
        ← large separation →
Within-class scatter

How spread out the samples are inside the same class. LDA tries to make this smaller.

Between-class scatter

How far the class centers are from each other. LDA tries to make this larger.

Core idea

LDA = maximize between-class separation and minimize within-class spread.

STEP 11 · LDA WORKFLOW

How LDA Works

Unlike PCA, LDA needs class labels because its objective explicitly depends on class separation.

Features X + Labels y
↓
Calculate class means
↓
Measure within-class scatter Sᵂ
↓
Measure between-class scatter Sᵇ
↓
Find directions maximizing separation
↓
Project data onto discriminant components

Objective intuition

Large distance between class centers
------------------------------------
Small spread inside each class

Important limitation

Maximum components = C − 1

If there are C classes, classical LDA can produce at most C - 1 discriminant components.

ClassesMaximum LDA components

STEP 12 · PRACTICAL

LDA with Python

Use the Iris dataset to reduce four input features to two discriminant components using known class labels.

from sklearn.datasets import load_iris
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis

iris = load_iris()
X = iris.data
y = iris.target

lda = LinearDiscriminantAnalysis(n_components=2)
X_reduced = lda.fit_transform(X, y)

print("Original shape:", X.shape)
print("Reduced shape:", X_reduced.shape)
NOTICE

fit_transform(X, y) receives both the features X and labels y. This is the key difference from PCA.

STEP 13 · ICA

Independent Component Analysis

ICA tries to separate observed data into statistically independent underlying source signals.

The cocktail-party problem

Imagine two people speaking at the same time while two microphones record mixtures of both voices.

Person A ─┐               ┌→ Microphone 1 = mixture
          ├→ room mixing ┤
Person B ─┘               └→ Microphone 2 = mixture
x1 = 0.7 * voice_A + 0.3 * voice_B
x2 = 0.4 * voice_A + 0.6 * voice_B

ICA tries to recover the original independent sources:

Observed mixtures X
↓ ICA
Estimated independent components
↓
Source A + Source B
ICA keyword

Independence. ICA searches for components that are as statistically independent as possible.

STEP 14 · ICA WORKFLOW

ICA Model and Practical

ICA assumes that the observed signals are mixtures of hidden independent sources.

X = A · S
SymbolMeaning
XObserved mixed signals.
SUnknown independent source signals.
AUnknown mixing matrix.

ICA tries to estimate an unmixing matrix W so that:

S_estimated = W · X

Python example

import numpy as np
from sklearn.decomposition import FastICA

X = np.array([
    [1.0, 1.5],
    [2.0, 1.0],
    [3.0, 2.5],
    [4.0, 2.0],
    [5.0, 3.5]
])

ica = FastICA(n_components=2, random_state=0)
S = ica.fit_transform(X)

print(S)
IMPORTANT

PCA creates uncorrelated components. ICA aims for the stronger condition of statistical independence.

STEP 17 · REVISION

Dimensionality Reduction Revision

Review the core ideas before moving to non-parametric methods and clustering.

What is dimensionality reduction?
Representing data with fewer features or dimensions while trying to preserve useful information.
What is the curse of dimensionality?
Problems that arise as dimensions increase, including sparse data, higher computation, overfitting risk, and less meaningful distance relationships.
Feature selection vs feature extraction?
Feature selection keeps a subset of existing features. Feature extraction creates new transformed features from the originals.
What does PCA optimize?
PCA finds directions containing maximum variance.
What does an eigenvector represent in PCA?
A principal direction in feature space.
What does an eigenvalue represent in PCA?
The amount of variance captured along the corresponding eigenvector.
What does LDA optimize?
Large separation between classes and small spread within each class.
Why does LDA need labels?
Because it must know which samples belong to each class to calculate within-class and between-class scatter.
What does ICA optimize?
ICA searches for statistically independent components or source signals.
PCA vs ICA?
PCA finds uncorrelated directions with high variance. ICA tries to recover statistically independent components.
