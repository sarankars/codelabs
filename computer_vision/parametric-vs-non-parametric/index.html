Parametric vs Non-Parametric Methods

Both approaches learn patterns from data. The key difference is whether we assume a fixed mathematical form for the data.

Main idea:

Parametric: choose a fixed model and learn its parameters.
Non-parametric: avoid assuming one fixed distribution and rely more directly on the observed data.

STEP 2 · PARAMETRIC

Parametric = Assume a Model, Learn Its Parameters

A parametric method starts with a fixed mathematical form and learns the values that describe it.

Fixed form

For example, we may assume the data follows a Gaussian, or bell-shaped, distribution.

Learned parameters

For a Gaussian distribution, important parameters include the mean and standard deviation.

Simple example:

Suppose the measured heights are roughly bell-shaped. Instead of keeping every value as the model, we may summarize the distribution using mean = 170 cm and standard deviation = 7 cm.

Many observations
↓ assume a Gaussian form
Estimate mean + standard deviation
↓
Use those values as the model
REMEMBER

Parametric does not mean “better.” It describes a model whose mathematical form is fixed and represented by a fixed set of parameters.

STEP 3 · NON-PARAMETRIC

Non-Parametric = Use the Data More Directly

A non-parametric method does not force the data into one fixed probability distribution. It often makes decisions from nearby samples or from the density of the observed data.

Think of it like this:

Instead of saying, “The data must follow this exact distribution,” we ask, “What do the actual samples around this point tell us?”

Training samples
↓
No fixed distribution assumption
↓
Use neighbors or local density
↓
Make a decision
IMPORTANT

Non-parametric does not mean zero settings. KNN still has K, and KDE has bandwidth. The term means the model is not restricted to one fixed distribution described by a fixed number of distribution parameters.

STEP 5 · METHOD 1

Nearest Neighbor (1-NN)

1-NN classifies a new sample by finding the single closest training sample and copying its class.

AA?BB
New sample
↓ calculate distance to every training sample
Find the closest sample
↓
Use that sample's class
Fruit example:

Known fruit weights are 145 g Apple, 155 g Apple, 165 g Apple, 185 g Orange, 195 g Orange and 205 g Orange. For a new fruit weighing 160 g, the nearest known weight is 155 g or 165 g, both Apples, so the prediction is Apple.

Distance

With one feature, distance is simply the absolute difference. With several numeric features, Euclidean distance is commonly used.

One-feature example:

Distance between 160 g and 155 g = |160 - 155| = 5.

STEP 6 · COMPLETE EXAMPLE

Build 1-NN from Scratch

This complete example calculates the distance to every training sample manually, finds the nearest one and predicts its class.

import numpy as np

# ---------------------------------
# 1. Create the training data
# ---------------------------------
# Each row has one feature: fruit weight in grams
X_train = np.array([
    [145],
    [155],
    [165],
    [185],
    [195],
    [205]
])

# Class label for each training sample
y_train = np.array([
    'Apple',
    'Apple',
    'Apple',
    'Orange',
    'Orange',
    'Orange'
])

# ---------------------------------
# 2. Create a new unknown sample
# ---------------------------------
new_sample = np.array([160])

# ---------------------------------
# 3. Calculate distance from the
#    new sample to every training sample
# ---------------------------------
distances = np.abs(X_train[:, 0] - new_sample[0])

print('Distances:', distances)

# ---------------------------------
# 4. Find the index of the smallest distance
# ---------------------------------
nearest_index = np.argmin(distances)

print('Nearest index:', nearest_index)
print('Nearest weight:', X_train[nearest_index, 0])

# ---------------------------------
# 5. Copy the class of the nearest sample
# ---------------------------------
prediction = y_train[nearest_index]

print('Predicted class:', prediction)
Expected output:
Distances: [15  5  5 25 35 45]
Nearest index: 1
Nearest weight: 155
Predicted class: Apple
STEP 7 · CODE EXPLANATION

Understand the 1-NN Program Step by Step

Follow the program in the same order in which the algorithm works.

  1. X_train stores the feature values. Here the only feature is weight.
  2. y_train stores the correct class for each training sample.
  3. new_sample = np.array([160]) is the unknown fruit.
  4. np.abs(X_train[:, 0] - new_sample[0]) calculates the distance from 160 to every known weight.
  5. np.argmin(distances) returns the index of the smallest distance.
  6. y_train[nearest_index] gives the label of the closest training sample.
TIE NOTE

In this example, 155 g and 165 g are equally close to 160 g. Both are Apples, so the prediction is still clear. In general, tie handling should be defined when equal-distance samples have different labels.

1-NN in one sentence:

Find the single closest known sample and use its class.

STEP 8 · METHOD 2

K-Nearest Neighbors (KNN)

KNN extends 1-NN by looking at several nearby samples instead of trusting only one.

New sample
↓
Calculate distances
↓
Select the K closest samples
↓
Count their class labels
↓
Majority vote = prediction
Example with K = 3:

If the three nearest samples are Apple, Apple, Orange, Apple receives two votes and Orange receives one. The prediction is Apple.

K = 1

Uses only one neighbor and can be sensitive to noise.

Small odd K

Values such as 3 or 5 are easy to understand and reduce simple voting ties.

Very large K

May include too many distant points and make predictions too general.

STEP 9 · COMPLETE EXAMPLE

Build KNN from Scratch

This example uses two features—weight and color score—and performs the complete KNN process manually.

import numpy as np
from collections import Counter

# ---------------------------------
# 1. Create the training data
# ---------------------------------
# Features = [weight_in_grams, color_score]
# Smaller color score = more red
# Larger color score = more orange
X_train = np.array([
    [145, 2],
    [155, 3],
    [165, 3],
    [185, 8],
    [195, 9],
    [205, 9]
], dtype=float)

y_train = np.array([
    'Apple',
    'Apple',
    'Apple',
    'Orange',
    'Orange',
    'Orange'
])

# ---------------------------------
# 2. New sample to classify
# ---------------------------------
new_sample = np.array([170, 4], dtype=float)

# ---------------------------------
# 3. Calculate Euclidean distances
# ---------------------------------
differences = X_train - new_sample
distances = np.sqrt(np.sum(differences ** 2, axis=1))

print('Distances:', distances)

# ---------------------------------
# 4. Sort samples from nearest to farthest
# ---------------------------------
sorted_indices = np.argsort(distances)

print('Nearest order:', sorted_indices)

# ---------------------------------
# 5. Select the K nearest samples
# ---------------------------------
K = 3
nearest_indices = sorted_indices[:K]
nearest_labels = y_train[nearest_indices]

print('Nearest labels:', nearest_labels)

# ---------------------------------
# 6. Majority vote
# ---------------------------------
votes = Counter(nearest_labels)
prediction = votes.most_common(1)[0][0]

print('Votes:', votes)
print('Predicted class:', prediction)
Expected result:

The new sample [170, 4] is much closer to the Apple samples than to the Orange samples, so the three nearest neighbors vote for Apple.

The same idea using scikit-learn

from sklearn.neighbors import KNeighborsClassifier

model = KNeighborsClassifier(n_neighbors=3)
model.fit(X_train, y_train)

prediction = model.predict([[170, 4]])
print('Predicted class:', prediction[0])
STEP 10 · CODE EXPLANATION

Understand the KNN Program Step by Step

KNN follows the same logic every time: measure, sort, select and vote.

  1. X_train contains two features for every fruit: weight and color score.
  2. new_sample contains the same two features for the unknown fruit.
  3. X_train - new_sample calculates the difference in each feature.
  4. np.sqrt(np.sum(differences ** 2, axis=1)) calculates Euclidean distance.
  5. np.argsort(distances) returns the sample indices from nearest to farthest.
  6. sorted_indices[:K] keeps only the first K neighbors.
  7. Counter(nearest_labels) counts how many votes each class receives.
  8. most_common(1) selects the class with the most votes.
What does K = 3 mean?

The prediction is based only on the three closest training samples.

FEATURE SCALE

If one feature has much larger numeric values than another, it can dominate Euclidean distance. In real datasets, feature scaling such as standardization is often important before KNN.

STEP 11 · COMPUTER VISION

How KNN Fits into Image Classification

An image can be represented using measurable features. KNN then compares the feature vector of a new image with feature vectors from known images.

KNN

Example:

For fruit images, features could include average color, area, roundness and texture. A new fruit image is converted into the same feature values before KNN compares it with known samples.

CONNECTION TO DIMENSIONALITY REDUCTION

PCA, LDA or ICA can first transform a large feature set into fewer useful features. Those reduced features can then be passed to a classifier such as KNN.

STEP 12 · METHOD 3

Parzen Window / Kernel Density Estimation

KDE asks a different question from KNN: “Where is the data concentrated?” It estimates the probability density directly from the observed samples.

Simple picture:

Imagine placing a small smooth hill on every data point. Where many hills overlap, the estimated density becomes high. Where there are few points, the density stays low.

Observed samples
↓
Place a window or smooth kernel around each sample
↓
Add their contributions
↓
Estimated density curve
Parzen Window

Uses a window around a location and estimates density from the samples that fall near it.

Kernel Density Estimation

Uses smooth kernels, commonly Gaussian kernels, to produce a smooth density estimate.

Key difference:

KNN: “Which nearby labels should vote?”
KDE: “How densely packed is the data here?”

STEP 13 · COMPLETE EXAMPLE

Implement Parzen Window and KDE

Start with a simple Parzen Window calculation, then build a smooth Kernel Density Estimate from the same idea.

Part A — Simple Parzen Window from Scratch

We choose a center point and a window width. Then we count how many observations fall inside that window.

import numpy as np

# ---------------------------------
# 1. Observed samples
# ---------------------------------
heights = np.array([160, 162, 163, 165, 180, 181], dtype=float)

# ---------------------------------
# 2. Choose the location where
#    density will be estimated
# ---------------------------------
center = 163

# Window half-width
# The window will cover center - h to center + h
h = 3

# ---------------------------------
# 3. Check which samples are
#    inside the window
# ---------------------------------
inside_window = np.abs(heights - center) <= h

print('Inside window:', inside_window)

# ---------------------------------
# 4. Count samples inside the window
# ---------------------------------
count = np.sum(inside_window)
print('Number of nearby samples:', count)

# ---------------------------------
# 5. Simple 1D Parzen density estimate
# ---------------------------------
N = len(heights)
window_width = 2 * h

density = count / (N * window_width)

print('Estimated density:', density)
What happened?

With center = 163 and h = 3, the window covers 160 to 166. The values 160, 162, 163 and 165 fall inside, so this region has relatively high local density.

Part B — Smooth KDE with a Gaussian Kernel

import numpy as np
import matplotlib.pyplot as plt
from sklearn.neighbors import KernelDensity

# ---------------------------------
# 1. Create the observed samples
# ---------------------------------
heights = np.array([
    160, 162, 163, 165,
    180, 181
], dtype=float)

# scikit-learn expects a 2D array:
# [160, 162, ...] becomes [[160], [162], ...]
X = heights.reshape(-1, 1)

# ---------------------------------
# 2. Create the KDE model
# ---------------------------------
kde = KernelDensity(
    kernel='gaussian',
    bandwidth=3
)

# ---------------------------------
# 3. Fit the model using the samples
# ---------------------------------
kde.fit(X)

# ---------------------------------
# 4. Create many x-values where
#    we want to estimate density
# ---------------------------------
x_plot = np.linspace(150, 190, 400).reshape(-1, 1)

# ---------------------------------
# 5. Estimate density
# ---------------------------------
# score_samples returns log-density
log_density = kde.score_samples(x_plot)

# Convert log-density back to normal density
density = np.exp(log_density)

# ---------------------------------
# 6. Plot the estimated density
# ---------------------------------
plt.figure(figsize=(9, 5))
plt.plot(x_plot[:, 0], density, label='Estimated density')
plt.scatter(
    heights,
    np.zeros_like(heights),
    marker='|',
    s=180,
    label='Observed samples'
)
plt.xlabel('Height (cm)')
plt.ylabel('Estimated density')
plt.title('Kernel Density Estimation')
plt.legend()
plt.grid(alpha=0.25)
plt.show()
Important:

score_samples() returns log-density values. np.exp() converts them back into ordinary density values.

STEP 14 · CODE EXPLANATION

Understand the KDE Program Step by Step

KDE does not predict a class directly in this example. It builds a smooth description of where the observed values are concentrated.

Part A — Parzen Window

  1. center = 163 is the location where we want to measure local density.
  2. h = 3 makes the window extend 3 units on each side, so the interval is 160 to 166.
  3. np.abs(heights - center) <= h checks which samples fall inside that interval.
  4. np.sum(inside_window) counts the nearby samples.
  5. count / (N * window_width) converts that count into a simple one-dimensional density estimate.

Part B — Smooth KDE

  1. heights contains the observed values.
  2. reshape(-1, 1) converts the one-dimensional NumPy array into the 2D shape expected by scikit-learn.
  3. KernelDensity(kernel='gaussian', bandwidth=3) chooses a Gaussian kernel and a smoothing width of 3.
  4. kde.fit(X) stores the observed samples used to build the density estimate.
  5. np.linspace(150, 190, 400) creates many positions between 150 and 190 where density will be evaluated.
  6. kde.score_samples(x_plot) calculates the log-density at every position.
  7. np.exp(log_density) converts log-density to ordinary density.
  8. plt.plot(...) draws the smooth density curve.

What does bandwidth do?

BandwidthEffect
SmallMore detailed, narrow peaks; can become noisy.
ModerateBalances local detail and smoothness.
LargeVery smooth curve; separate groups may merge together.
KDE in one sentence:

Estimate where data is concentrated by adding smooth contributions around the observed samples.

STEP 15 · CONNECT EVERYTHING

1-NN vs KNN vs KDE

All three are non-parametric methods, but they solve different parts of a pattern-analysis problem.

MethodMain questionMain output
1-Nearest NeighborWhich single training sample is closest?A class from the closest sample
K-Nearest NeighborsWhat do the K nearest labeled samples vote for?A class or regression value
Parzen / KDEWhere is the observed data concentrated?An estimated probability density
Do not confuse them:

1-NN uses one neighbor. KNN uses several neighbors. KDE estimates density rather than performing majority voting.

Use these questions to review the complete topic.

1. What is a parametric method?
A method that assumes a fixed mathematical form and learns the parameters that describe that form.
2. What is a non-parametric method?
A method that does not require one fixed distribution form and relies more directly on the observed data.

No. KNN has K and KDE has bandwidth. “Non-parametric” refers to the absence of a fixed finite-parameter distributional form.

A KDE setting that controls how narrow or smooth the estimated density curve is.
