Step 1 · Two video questions

Where did the scene change—and what is moving?

Video is a sequence of images. Comparing those images over time lets us divide a movie into shots or separate foreground motion from a learned background.

Application A

Shot-boundary detection

Find the frame where one camera shot ends and another begins. Editors, search systems, and video summarizers use these boundaries.

Application B

Background subtraction

Model the stable scene and label pixels that no longer fit it. Traffic monitoring and fixed security cameras use foreground masks.

Learning outcomes

  • Compare neighboring frames using color histograms.
  • Turn a distance score into a hard-cut decision.
  • Explain how MOG2 learns a changing background.
  • Diagnose camera motion, shadows, and gradual transitions.
Prerequisite: Complete Segmentation Fundamentals first. Here, the extra feature is time: the previous frames help interpret the current one.
Step 2 · Divide a video

A shot boundary is a large visual change

A hard cut replaces one shot with another between two consecutive frames. We can compare compact color summaries instead of every pixel position.

Read frames

Take frames t−1 and t.

Make histograms

Count HSV colors and normalize the counts.

Compare

Use Bhattacharyya distance: 0 is similar, 1 is different.

Threshold

Mark a cut when distance is above the chosen limit.

Why HSV histograms?

Hue and saturation summarize the color distribution while ignoring exact object positions. A beach and a dark indoor room usually have very different distributions even if objects move inside each shot.

Important: a score is evidence, not meaning. A camera flash can create a large score without a new shot; a dissolve may spread a smaller change over many frames.
Core OpenCV operation
hist = cv2.calcHist([hsv], [0, 1], None, [30, 32], [0, 180, 0, 256])
cv2.normalize(hist, hist)
distance = cv2.compareHist(previous_hist, hist, cv2.HISTCMP_BHATTACHARYYA)
is_cut = distance > threshold

Step 4 · Learn the scene

Background subtraction creates a foreground mask

MOG2 keeps a statistical model for each pixel. A new value that does not fit the learned history is marked as foreground.

Background model

Several Gaussian distributions represent common values such as waving leaves, shadows, or an empty road.

Foreground mask

Pixels unlike the model become white. Morphological opening can remove isolated noise after subtraction.

MOG2 loop
subtractor = cv2.createBackgroundSubtractorMOG2(
    history=300, varThreshold=24, detectShadows=True)

while True:
    ok, frame = video.read()
    if not ok:
        break
    foreground = subtractor.apply(frame)
    clean = cv2.morphologyEx(foreground, cv2.MORPH_OPEN, kernel)
Step 5 · Know the assumptions

Both methods can fail for understandable reasons

Diagnose the input and score before changing parameters.

Shot detection

Gradual transition

A fade or dissolve distributes change across several frames. Add a sliding-window accumulated score.

Shot detection

Flash or fast motion

A flash produces a temporary spike. Check whether the following frame returns to the earlier distribution.

Background

Moving camera

Nearly every pixel changes. Stabilize the video or use motion compensation before subtraction.

Background

Shadows and stopped objects

Shadows may enter the mask; an object that remains still long enough may be absorbed into the model.

Safe media handling

  • Check that VideoCapture opened successfully.
  • Stop cleanly when a frame cannot be read.
  • Log the frame number, timestamp, score, and threshold for every boundary.
  • Test on a short annotated sequence before processing a long video.
