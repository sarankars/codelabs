STEP 4 · PREPROCESSING

Standardise the Image Matrix

PCA is sensitive to scale. We standardise each pixel feature so that no pixel dominates just because of its brightness range.

Why standardise?

Without standardisation

PCA directions are dominated by features with the largest numerical range, not the most informative ones.

With standardisation

Every pixel has mean 0 and variance 1, so PCA looks for the most informative directions regardless of raw scale.

pca_images.py — Part 2: standardisation
# Standardise: zero mean, unit variance per pixel
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

print("Scaled matrix shape:", X_scaled.shape)
print("Mean of first feature (should be ~0):", round(X_scaled[:, 0].mean(), 4))
print("Std  of first feature (should be ~1):", round(X_scaled[:, 0].std(), 4))

STEP 5 · PCA

Apply PCA to the Image Matrix

Use scikit-learn’s PCA class to find the principal components of the face dataset, keeping 150 components to start.

pca_images.py — Part 3: apply PCA
N_COMPONENTS = 150   # we will experiment with this later

pca = PCA(n_components=N_COMPONENTS, whiten=True, random_state=42)
X_pca = pca.fit_transform(X_scaled)

print(f"PCA applied:")
print(f"  Original  : {X_scaled.shape}")
print(f"  Compressed: {X_pca.shape}")
print(f"  Ratio     : {X_pca.shape[1]/X_scaled.shape[1]:.2%} of original features")

cum_var = np.cumsum(pca.explained_variance_ratio_)
print(f"\nVariance explained by top {N_COMPONENTS} components: {cum_var[-1]:.2%}")
expected output PCA applied: Original : (400, 4096) Compressed: (400, 150) Ratio : 3.66% of original features Variance explained by top 150 components: 99.xx%

Understand the output

VariableShapeMeaning
X_scaled(400, 4096)Standardised full image matrix
X_pca(400, 150)Compressed representation
pca.components_(150, 4096)Eigenfaces (principal directions)
pca.explained_variance_ratio_(150,)Fraction of variance each PC captures
pca.mean_(4096,)Mean face (per-pixel average)
PARAMETER

whiten=True divides each component by its standard deviation. This gives components with unit variance and often helps downstream classifiers.

Reading the chart
  • The first few bars are tall — those components explain a lot.
  • The curve flattens quickly — a small number of components carries most information.
  • This is the power of PCA: enormous compression with minimal information loss.

What do eigenfaces look like?

They look like ghostly, abstract face patterns. PC1 captures the most common variation (e.g. overall lighting). Later PCs capture finer details like eye shape or hair texture.

INSIGHT

Each original face image can be expressed as a weighted sum of eigenfaces plus the mean face. PCA compression means keeping only the weights for the top-k eigenfaces.

STEP 8 · RECONSTRUCTION

Reconstruct Images from Compressed Representations

After compressing with PCA, we can reconstruct approximate versions of the original images. Quality improves as we keep more components.

pca_images.py — Part 6: reconstruction
def reconstruct(X_scaled, n_components, image_shape=(64, 64)):
    """Compress X with n_components PCA dimensions and reconstruct."""
    pca_k   = PCA(n_components=n_components, whiten=True, random_state=42)
    X_proj  = pca_k.fit_transform(X_scaled)
    X_recon = pca_k.inverse_transform(X_proj)
    X_recon = scaler.inverse_transform(X_recon)
    X_recon = np.clip(X_recon, 0, 1)
    return X_recon

levels = [1, 5, 10, 20, 50, 100, 150, 200]
sample_idx = 0
original_face = X[sample_idx].reshape(image_shape)

fig, axes = plt.subplots(2, 4, figsize=(14, 7))
fig.suptitle("Image Reconstruction at Different Compression Levels", fontsize=13, fontweight="bold")

for ax, k in zip(axes.flat, levels):
    recon      = reconstruct(X_scaled, n_components=k)
    recon_face = recon[sample_idx].reshape(image_shape)
    mse        = np.mean((original_face - recon_face) ** 2)
    ax.imshow(recon_face, cmap="gray", vmin=0, vmax=1)
    ax.set_title(f"k={k}\nMSE={mse:.4f}", fontsize=9)
    ax.axis("off")

plt.tight_layout()
plt.savefig("05_reconstruction.png", dpi=120, bbox_inches="tight")
plt.show()
what to observe k=1 -> very blurry, only overall brightness captured k=5 -> rough face shape visible k=20 -> recognisable face, some smoothing k=100 -> nearly identical to original k=200 -> very close to lossless
MSE (Mean Squared Error)

MSE measures the average squared difference between original and reconstructed pixel values. Lower MSE = better reconstruction. As k increases, MSE decreases.

STEP 11 · ANALYSIS

Measure Compression Ratio

Quantify how much space is saved by PCA compression compared to storing the full images.

pca_images.py — Part 9: compression analysis
original_size = n_samples * n_features  # 400 x 4096 = 1,638,400

print("=" * 60)
print(f"{'Compression Summary':^60}")
print("=" * 60)
print(f"{'Components':>12}  {'Size (floats)':>14}  {'Saved':>7}  {'Var. explained':>16}")
print("-" * 60)

for k in [5, 10, 20, 50, 100, 150, 200]:
    compressed_size = n_samples * k + k * n_features
    saving = 1 - compressed_size / original_size
    pca_k  = PCA(n_components=k, random_state=42).fit(X_scaled)
    var_exp = np.sum(pca_k.explained_variance_ratio_)
    print(f"{k:>12}  {compressed_size:>14,}  {saving:>6.1%}  {var_exp:>15.2%}")

print("=" * 60)
print(f"{'Original':>12}  {original_size:>14,}  {'--':>7}  {'100.00%':>16}")
Trade-off

k = 50 saves ~87% of storage while preserving most recognisable image quality. This is the fundamental power and trade-off of PCA compression.

pca_images.py — COMPLETE SCRIPT
"""
pca_images.py
Implement Dimensionality Reduction using PCA for Images
Practical Codelab -- Computer Vision
"""

import numpy as np
import matplotlib.pyplot as plt
from sklearn.datasets import fetch_olivetti_faces
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

# 1. Load dataset
dataset = fetch_olivetti_faces(shuffle=True, random_state=42)
X = dataset.data          # (400, 4096)
y = dataset.target        # (400,)
n_samples, n_features = X.shape
image_shape = (64, 64)
print(f"Loaded: {n_samples} images, {n_features} features")

# 2. Visualise samples
fig, axes = plt.subplots(2, 5, figsize=(12, 5))
fig.suptitle("Sample Raw Images", fontsize=13, fontweight="bold")
for ax, img, lbl in zip(axes.flat, X[:10], y[:10]):
    ax.imshow(img.reshape(image_shape), cmap="gray"); ax.set_title(f"P{lbl}"); ax.axis("off")
plt.tight_layout(); plt.savefig("01_raw_samples.png", dpi=120, bbox_inches="tight"); plt.show()

# 3. Standardise
scaler   = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 4. Apply PCA (150 components)
N_COMPONENTS = 150
pca   = PCA(n_components=N_COMPONENTS, whiten=True, random_state=42)
X_pca = pca.fit_transform(X_scaled)
print(f"Compressed: {X_scaled.shape} -> {X_pca.shape}")
print(f"Variance explained: {np.sum(pca.explained_variance_ratio_):.2%}")

# 5. Scree plot
pca_full = PCA(random_state=42).fit(X_scaled)
ev       = pca_full.explained_variance_ratio_
cum_ev   = np.cumsum(ev)
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 5))
fig.suptitle("Explained Variance", fontsize=13, fontweight="bold")
ax1.bar(range(1, 51), ev[:50], color="#2856d8", edgecolor="#101010", linewidth=0.8)
ax1.set(xlabel="Component", ylabel="Variance Ratio", title="Individual (first 50)")
ax2.plot(range(1, len(cum_ev)+1), cum_ev, color="#2856d8", linewidth=2)
for t, c in [(0.90, "#ff9bb7"), (0.95, "#ffd83d"), (0.99, "#75e6c5")]:
    ax2.axhline(t, color=c, linestyle="--", linewidth=1.5, label=f"{t:.0%}")
ax2.set(xlabel="Components", ylabel="Cumulative Variance", title="Cumulative", xlim=(0,200))
ax2.legend()
plt.tight_layout(); plt.savefig("02_scree_plot.png", dpi=120, bbox_inches="tight"); plt.show()
for t in [0.80, 0.90, 0.95, 0.99]:
    print(f"  {t:.0%} variance -> {np.argmax(cum_ev >= t)+1} components")

# 6. Mean face
plt.figure(figsize=(3, 3))
plt.imshow(pca.mean_.reshape(image_shape), cmap="gray")
plt.title("Mean Face", fontweight="bold"); plt.axis("off")
plt.tight_layout(); plt.savefig("03_mean_face.png", dpi=120, bbox_inches="tight"); plt.show()

# 7. Eigenfaces
fig, axes = plt.subplots(3, 5, figsize=(14, 9))
fig.suptitle("Top 15 Eigenfaces", fontsize=13, fontweight="bold")
for idx, ax in enumerate(axes.flat):
    ef = pca.components_[idx].reshape(image_shape)
    ef = (ef - ef.min()) / (ef.max() - ef.min())
    ax.imshow(ef, cmap="gray")
    ax.set_title(f"PC{idx+1}: {pca.explained_variance_ratio_[idx]:.2%}", fontsize=8); ax.axis("off")
plt.tight_layout(); plt.savefig("04_eigenfaces.png", dpi=120, bbox_inches="tight"); plt.show()

# 8. Reconstruction helper
def reconstruct(X_sc, k):
    pca_k = PCA(n_components=k, whiten=True, random_state=42)
    X_r   = pca_k.inverse_transform(pca_k.fit_transform(X_sc))
    return np.clip(scaler.inverse_transform(X_r), 0, 1)

# 9. Reconstruction gallery
levels = [1, 5, 10, 20, 50, 100, 150, 200]
orig   = np.clip(scaler.inverse_transform(X_scaled), 0, 1)
fig, axes = plt.subplots(2, 4, figsize=(14, 7))
fig.suptitle("Reconstruction at Different Compression Levels", fontsize=13, fontweight="bold")
for ax, k in zip(axes.flat, levels):
    rc  = reconstruct(X_scaled, k)[0].reshape(image_shape)
    mse = np.mean((orig[0].reshape(image_shape) - rc)**2)
    ax.imshow(rc, cmap="gray", vmin=0, vmax=1)
    ax.set_title(f"k={k}\nMSE={mse:.4f}", fontsize=9); ax.axis("off")
plt.tight_layout(); plt.savefig("05_reconstruction.png", dpi=120, bbox_inches="tight"); plt.show()

# 10. MSE curve
k_vals  = list(range(1, 21)) + list(range(25, 201, 5))
mse_arr = [np.mean((orig - reconstruct(X_scaled, k))**2) for k in k_vals]
fig, ax = plt.subplots(figsize=(10, 5))
ax.plot(k_vals, mse_arr, color="#2856d8", linewidth=2, marker=".", markersize=4)
ax.fill_between(k_vals, mse_arr, alpha=0.15, color="#2856d8")
ax.set(xlabel="k (components)", ylabel="MSE", title="Reconstruction Error vs. Components")
ax.axvline(50,  color="#ffd83d", linestyle="--", linewidth=1.5, label="k=50")
ax.axvline(100, color="#75e6c5", linestyle="--", linewidth=1.5, label="k=100")
ax.legend()
plt.tight_layout(); plt.savefig("06_mse_curve.png", dpi=120, bbox_inches="tight"); plt.show()

# 11. Comparison gallery
r50  = reconstruct(X_scaled, 50)
r150 = reconstruct(X_scaled, 150)
fig, axes = plt.subplots(3, 6, figsize=(16, 9))
fig.suptitle("Original  |  k=50  |  k=150", fontsize=13, fontweight="bold")
for col in range(6):
    idx = col * 5
    for row, (data, label) in enumerate([(orig,"Original"),(r50,"k=50"),(r150,"k=150")]):
        mse = "" if row==0 else f"\nMSE={np.mean((orig[idx]-data[idx])**2):.4f}"
        axes[row,col].imshow(data[idx].reshape(image_shape), cmap="gray", vmin=0, vmax=1)
        axes[row,col].set_title(f"{label}{mse}", fontsize=8); axes[row,col].axis("off")
plt.tight_layout(); plt.savefig("07_comparison_gallery.png", dpi=120, bbox_inches="tight"); plt.show()

# 12. Compression summary
orig_size = n_samples * n_features
print(f"\n{'='*60}\n{'Compression Summary':^60}\n{'='*60}")
print(f"{'k':>10}  {'Floats':>12}  {'Saved':>7}  {'Var%':>8}")
print("-"*45)
for k in [5, 10, 20, 50, 100, 150, 200]:
    sz = n_samples*k + k*n_features
    sv = 1 - sz/orig_size
    ve = np.sum(PCA(n_components=k, random_state=42).fit(X_scaled).explained_variance_ratio_)
    print(f"{k:>10}  {sz:>12,}  {sv:>6.1%}  {ve:>7.2%}")
print(f"{'Original':>10}  {orig_size:>12,}  {'--':>7}  {'100.00%':>8}")
print("\nAll outputs saved. Lab complete!")

IMAGE_DIR   = "my_faces/"      # folder containing .jpg or .png images
TARGET_SIZE = (64, 64)

images = []
for fname in sorted(os.listdir(IMAGE_DIR)):
    if fname.lower().endswith((".jpg", ".png", ".jpeg")):
        img = io.imread(os.path.join(IMAGE_DIR, fname))
        if img.ndim == 3:
            img = color.rgb2gray(img)
        img = transform.resize(img, TARGET_SIZE)
        images.append(img.flatten())

X_custom = np.array(images)
print(f"Custom dataset: {X_custom.shape}")

Key code patterns

1. Load and flatten images into a matrix
X = dataset.data — each row is one flattened image. Shape: (n_samples, n_pixels).
2. Standardise with StandardScaler
X_scaled = StandardScaler().fit_transform(X) — always fit on training data only.
3. Apply PCA
pca = PCA(n_components=k, whiten=True); X_pca = pca.fit_transform(X_scaled) — result shape: (n_samples, k).
4. Inspect explained variance
pca.explained_variance_ratio_ per component; np.cumsum(...) for cumulative.
5. Access eigenfaces
pca.components_[i].reshape(image_shape) — pca.components_ shape: (k, n_pixels).
6. Reconstruct images
X_recon = scaler.inverse_transform(pca.inverse_transform(X_pca)) — then clip to [0,1].
