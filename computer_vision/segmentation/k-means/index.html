STEP 1 · THE BIG IDEA

Put similar values into groups

K-means is a clustering algorithm. It finds groups in data without being told the name of each group.

By the end: You will segment an image into a small number of colour groups using Python, NumPy, and OpenCV—and understand every line you write.
K

The number of groups we want.

Cluster

One group of similar values.

Center

The average value of a cluster. It is also called a centroid.

A tiny example

For 2, 3, 4, 20, 22, 24 and K = 2, we expect one group near 3 and another near 22.

STEP 2 · DO IT BY HAND

Nearest center wins

Before using OpenCV, follow one round manually. This makes the library code much easier to understand.

Values: 2, 3, 4, 20, 22, 24
Starting centers: 3 and 20

For value 22:
Distance from 3  = |22 - 3|  = 19
Distance from 20 = |22 - 20| = 2

22 joins the second cluster.
K-means compares distances. The smaller distance decides the cluster.
Cluster 1

Values: 2, 3, 4
New center: (2 + 3 + 4) / 3 = 3

Cluster 2

Values: 20, 22, 24
New center: (20 + 22 + 24) / 3 = 22

THE REPEATING CYCLE

Assign every value to the nearest center → calculate new average centers → repeat until the centers barely change.

STEP 6 · KNOW WHEN TO STOP

Create the termination criteria

K-means repeats its assignment and averaging steps. The criteria tell OpenCV when it has done enough work.

criteria = (
    cv2.TERM_CRITERIA_EPS + cv2.TERM_CRITERIA_MAX_ITER,
    100,
    0.2
)
Read the tuple as: (how to stop, maximum loops, minimum change).
CodeEasy meaning
criteria = (Create a tuple named criteria.
TERM_CRITERIA_EPSAllow stopping when the centers change by only a tiny amount.
+Combine both stopping conditions.
TERM_CRITERIA_MAX_ITERAllow stopping at the maximum number of iterations.
100Never repeat more than 100 times.
0.2The epsilon, or tiny-change limit.
)Finish the tuple.
PLAIN ENGLISH

Stop when the centers settle within 0.2, or after 100 repetitions—whichever happens first. It does not always run 100 times.

The total squared distance between pixels and their centers. Smaller means tighter groups.

One cluster number—0, 1, or 2—for every pixel.

centers

The average BGR colour of every cluster.

K-means is not object recognition

It does not know “sky,” “grass,” or “car.” It only sees numbers and groups similar colours.

STEP 10 · PUT EVERYTHING TOGETHER

Run the complete segmentation program

The comments summarize why each part exists. Compare this final program with every earlier step.

import cv2
import numpy as np

# Read the image from the project folder.
image = cv2.imread("image.jpg")

# Stop early if the image could not be read.
if image is None:
    raise FileNotFoundError("Could not find image.jpg")

# Turn the image into rows of BGR pixels.
pixels = image.reshape(-1, 3)

# OpenCV K-means requires float32 input.
pixels = np.float32(pixels)

# Stop after convergence or at most 100 iterations.
criteria = (
    cv2.TERM_CRITERIA_EPS + cv2.TERM_CRITERIA_MAX_ITER,
    100,
    0.2
)

# Create three colour clusters.
k = 3

# Group similar pixel colours.
compactness, labels, centers = cv2.kmeans(
    pixels,
    k,
    None,
    criteria,
    10,
    cv2.KMEANS_PP_CENTERS
)

# Convert center colours to whole numbers from 0 to 255.
centers = np.uint8(centers)

# Replace every pixel with its cluster's center colour.
segmented_pixels = centers[labels.flatten()]

# Restore the original image dimensions.
segmented_image = segmented_pixels.reshape(image.shape)

# Display the original and segmented images.
cv2.imshow("Original Image", image)
cv2.imshow("K-Means Segmentation", segmented_image)

# Wait for a key, then close the windows.
cv2.waitKey(0)
cv2.destroyAllWindows()

Common errors

type == CV_32F

Your pixels are not float32. Add pixels = np.float32(pixels) before calling K-means.

data0.dims <= 2

You probably passed the original 3D image. Pass image.reshape(-1, 3).astype(np.float32).

The output groups unrelated objects

This is expected. Plain K-means groups colours, not objects, and it ignores pixel position.
