STEP 1 · GOAL

Build Your First Spring Boot CRUD API

We will create a very small Student REST API. To keep the first backend lesson easy, almost everything will live inside one controller file.

By the end: Create a Spring Boot project using start.spring.io, open it in VS Code, run it, create one StudentController.java, store students in an ArrayList, and implement GET, POST, PUT, and DELETE APIs.

Beginner-first design

No database, repository, service layer, DTO, or advanced architecture yet. First understand how an HTTP request reaches Java code.

ArrayList

Why the empty constructor?

When JSON arrives in a request body, Spring uses Jackson to create a Student object. A no-argument constructor plus setters makes that process simple for beginners.

STEP 10 · FIND ONE

GET One Student by ID

The value inside the URL becomes a Java method parameter using @PathVariable.

@GetMapping("/{id}")
public ResponseEntity<Student> getStudentById(@PathVariable int id) {
    for (Student student : students) {
        if (student.getId() == id) {
            return ResponseEntity.ok(student);
        }
    }

    return ResponseEntity.notFound().build();
}
Part Meaning
/{id} Creates a variable section in the URL.
@PathVariable int id Reads that URL value into Java.
ResponseEntity.ok(student) Returns 200 OK with the Student as JSON.
notFound() Returns 404 when no matching student exists.

STEP 12 · UPDATE

PUT to Update a Student

We find the existing student by ID, then copy the new values from the request body.

@PutMapping("/{id}")
public ResponseEntity<Student> updateStudent(
        @PathVariable int id,
        @RequestBody Student updatedStudent) {

    for (Student student : students) {
        if (student.getId() == id) {
            student.setName(updatedStudent.getName());
            student.setAge(updatedStudent.getAge());
            student.setCourse(updatedStudent.getCourse());

            return ResponseEntity.ok(student);
        }
    }

    return ResponseEntity.notFound().build();
}

Example request

PUT /api/students/1

{
  "name": "Asha Sharma",
  "age": 21,
  "course": "AI & ML"
}
Why not replace the ID?

The ID comes from the URL and identifies which existing student we are editing. We only update the editable fields.

STEP 13 · DELETE

DELETE a Student

Use the ID in the URL and remove the matching item from the ArrayList.

@DeleteMapping("/{id}")
public ResponseEntity<Void> deleteStudent(@PathVariable int id) {
    for (Student student : students) {
        if (student.getId() == id) {
            students.remove(student);
            return ResponseEntity.noContent().build();
        }
    }

    return ResponseEntity.notFound().build();
}
DELETE /api/students/2
↓ @PathVariable
find matching student
↓ remove from ArrayList
↓
204 No Content

If not found → 404 Not Found
NOTE

We return no response body after a successful delete, so 204 No Content is appropriate.

STEP 14 · PUT IT TOGETHER

Complete StudentController.java

At this point your entire CRUD backend, apart from the generated Spring Boot main class, is in this one file.

package com.example.studentapi;

import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

import java.util.ArrayList;
import java.util.List;

@RestController
@RequestMapping("/api/students")
public class StudentController {

    private final List<Student> students = new ArrayList<>();
    private int nextId = 1;

    public StudentController() {
        students.add(new Student(nextId++, "Asha", 20, "CSE"));
        students.add(new Student(nextId++, "Rahul", 21, "ECE"));
    }

    @GetMapping
    public List<Student> getAllStudents() {
        return students;
    }

    @GetMapping("/{id}")
    public ResponseEntity<Student> getStudentById(@PathVariable int id) {
        for (Student student : students) {
            if (student.getId() == id) {
                return ResponseEntity.ok(student);
            }
        }
        return ResponseEntity.notFound().build();
    }

    @PostMapping
    public ResponseEntity<Student> createStudent(@RequestBody Student student) {
        student.setId(nextId++);
        students.add(student);
        return ResponseEntity.status(201).body(student);
    }

    @PutMapping("/{id}")
    public ResponseEntity<Student> updateStudent(
            @PathVariable int id,
            @RequestBody Student updatedStudent) {

        for (Student student : students) {
            if (student.getId() == id) {
                student.setName(updatedStudent.getName());
                student.setAge(updatedStudent.getAge());
                student.setCourse(updatedStudent.getCourse());
                return ResponseEntity.ok(student);
            }
        }
        return ResponseEntity.notFound().build();
    }

    @DeleteMapping("/{id}")
    public ResponseEntity<Void> deleteStudent(@PathVariable int id) {
        for (Student student : students) {
            if (student.getId() == id) {
                students.remove(student);
                return ResponseEntity.noContent().build();
            }
        }
        return ResponseEntity.notFound().build();
    }

    public static class Student {
        private int id;
        private String name;
        private int age;
        private String course;

        public Student() {
        }

        public Student(int id, String name, int age, String course) {
            this.id = id;
            this.name = name;
            this.age = age;
            this.course = course;
        }

        public int getId() {
            return id;
        }

        public void setId(int id) {
            this.id = id;
        }

        public String getName() {
            return name;
        }

        public void setName(String name) {
            this.name = name;
        }

        public int getAge() {
            return age;
        }

        public void setAge(int age) {
            this.age = age;
        }

        public String getCourse() {
            return course;
        }

        public void setCourse(String course) {
            this.course = course;
        }
    }
}

STEP 17 · REVISION

Student CRUD API Revision

Review the ideas before connecting this backend to Flutter.

What does @RestController do?
It tells Spring that the class contains REST endpoints whose return values should be written to the HTTP response.
What does @RequestMapping("/api/students") do?
It gives every endpoint in the controller the same base URL.
What does @PathVariable do?
It reads a dynamic value such as the student ID from the URL.
What does @RequestBody do?
It tells Spring/Jackson to convert incoming JSON into a Java object.
Where are students stored?
Inside an in-memory ArrayList<Student> declared directly in StudentController.
Why does data disappear after restart?
There is no database. The ArrayList exists only while the Java process is running.
