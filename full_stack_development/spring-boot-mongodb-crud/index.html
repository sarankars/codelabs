Spring Boot & MongoDB CRUD API

Learn how to build a production-grade REST API in Java using Spring Boot 3 and MongoDB. You will understand the document-based NoSQL model, configure Spring Data MongoDB, create a comprehensive Student entity, and implement full CRUD operations.

🎯 Goal: Understand the architecture of Spring Boot + MongoDB, differentiate NoSQL from Relational databases, and set up your local development environment.

Why MongoDB with Spring Boot?

In previous modules, you worked with relational databases (MySQL, PostgreSQL, H2) where data is strictly stored in tables with rows and fixed columns governed by foreign keys and schemas. MongoDB is a leading NoSQL document database that stores data in flexible, JSON-like structures called BSON (Binary JSON).

Relational (SQL / Hibernate)

Data is organized into normalized tables with rows and columns. Schemas are rigid and alterations require schema migrations (ALTER TABLE). Relationships require JOINs.

Document Store (MongoDB)

Data is stored in self-contained JSON/BSON documents inside collections. Schema is dynamic and polymorphic, allowing rich embedded arrays and nested sub-documents.

RDBMS vs MongoDB Terminology Mapping

Relational Database (SQL) MongoDB (NoSQL) Spring Boot Concept
Database Database (e.g. studentdb) Configured in application.properties
Table Collection (e.g. students) Annotated with @Document(collection="students")
Row / Record Document (BSON JSON object) Instance of Student class
Column / Field Field / Key-Value Pair Java class field (e.g. String email)
Primary Key (ID) _id (ObjectId or custom string) Field annotated with @Id
JpaRepository MongoRepository MongoRepository<Student, String>

# Application Server Port
server.port=8080

# -------------------------------------------------------------
# OPTION A: Local MongoDB (Default port 27017, database: studentdb)
# -------------------------------------------------------------
spring.data.mongodb.uri=mongodb://localhost:27017/studentdb

# Enable automatic index creation for @Indexed annotations
spring.data.mongodb.auto-index-creation=true

# Show logging for Spring Data MongoDB queries
logging.level.org.springframework.data.mongodb.core.MongoTemplate=DEBUG

Connecting to MongoDB Atlas (Cloud)

If you are using a free MongoDB Atlas cluster, simply replace the URI with your Atlas SRV connection string:

spring.data.mongodb.uri=mongodb+srv://admin:YourSecurePassword@cluster0.abcde.mongodb.net/studentdb?retryWrites=true&w=majority

Note: Remember to whitelist your current IP address (or 0.0.0.0/0 for development) in the Atlas Network Access panel!

2. Key Configuration Insights

Dynamic Database Creation

You do not need to run CREATE DATABASE studentdb; upfront! MongoDB creates databases and collections lazily on the fly when the first document is written.

auto-index-creation=true

In Spring Boot 3, automatic index creation is disabled by default for performance. Setting spring.data.mongodb.auto-index-creation=true guarantees that unique indices like email and rollNumber are automatically enforced.

Create the Student Document Model

Model the Student entity using Spring Data MongoDB annotations like @Document, @Id, @Field, and @Indexed.

🎯 Goal: Build Student.java, understand BSON ObjectId mapping, and validate fields with Jakarta annotations.

1. MongoDB Document Annotations

  • @Document(collection = "students"): Marks this Java class as a MongoDB document and specifies the target collection name.
  • @Id: Marks the primary key field. In MongoDB, this maps directly to the _id field in BSON.
  • @Indexed(unique = true): Requests an index on the field in MongoDB, enforcing unique constraint checks.
  • @Field("field_name"): Customizes the BSON key name if you want it different from the Java property name.
NOTE ON @Id IN MONGODB Why is id a String instead of Long? MongoDB uses a 12-byte BSON ObjectId (represented as a 24-character hexadecimal string, e.g., 652d8b4e7a83f91038e21a4f). Using String id allows Spring Data to automatically generate and convert between String and ObjectId!

2. Complete Student.java Implementation

Create src/main/java/com/example/studentmongodb/model/Student.java:

package com.example.studentmongodb.model;

import jakarta.validation.constraints.Email;
import jakarta.validation.constraints.Max;
import jakarta.validation.constraints.Min;
import jakarta.validation.constraints.NotBlank;
import org.springframework.data.annotation.Id;
import org.springframework.data.mongodb.core.index.Indexed;
import org.springframework.data.mongodb.core.mapping.Document;
import org.springframework.data.mongodb.core.mapping.Field;

import java.time.LocalDateTime;
import java.util.ArrayList;
import java.util.List;

@Document(collection = "students")
public class Student {

    @Id
    private String id;

    @NotBlank(message = "Roll number is required")
    @Indexed(unique = true)
    @Field("roll_number")
    private String rollNumber;

    @NotBlank(message = "First name is required")
    @Field("first_name")
    private String firstName;

    @NotBlank(message = "Last name is required")
    @Field("last_name")
    private String lastName;

    @NotBlank(message = "Email is required")
    @Email(message = "Email format is invalid")
    @Indexed(unique = true)
    private String email;

    @NotBlank(message = "Course is required")
    private String course;

    @Min(value = 0, message = "GPA cannot be negative")
    @Max(value = 4, message = "GPA maximum is 4.0")
    private Double gpa;

    private List<String> skills = new ArrayList<>();

    private LocalDateTime createdAt = LocalDateTime.now();

    // Default Constructor (Required by Spring Data / Jackson)
    public Student() {
    }

    // Parameterized Constructor (Convenience)
    public Student(String rollNumber, String firstName, String lastName, String email, String course, Double gpa, List<String> skills) {
        this.rollNumber = rollNumber;
        this.firstName = firstName;
        this.lastName = lastName;
        this.email = email;
        this.course = course;
        this.gpa = gpa;
        this.skills = skills != null ? skills : new ArrayList<>();
        this.createdAt = LocalDateTime.now();
    }

    // Getters and Setters
    public String getId() {
        return id;
    }

    public void setId(String id) {
        this.id = id;
    }

    public String getRollNumber() {
        return rollNumber;
    }

    public void setRollNumber(String rollNumber) {
        this.rollNumber = rollNumber;
    }

    public String getFirstName() {
        return firstName;
    }

    public void setFirstName(String firstName) {
        this.firstName = firstName;
    }

    public String getLastName() {
        return lastName;
    }

    public void setLastName(String lastName) {
        this.lastName = lastName;
    }

    public String getEmail() {
        return email;
    }

    public void setEmail(String email) {
        this.email = email;
    }

    public String getCourse() {
        return course;
    }

    public void setCourse(String course) {
        this.course = course;
    }

    public Double getGpa() {
        return gpa;
    }

    public void setGpa(Double gpa) {
        this.gpa = gpa;
    }

    public List<String> getSkills() {
        return skills;
    }

    public void setSkills(List<String> skills) {
        this.skills = skills;
    }

    public LocalDateTime getCreatedAt() {
        return createdAt;
    }

    public void setCreatedAt(LocalDateTime createdAt) {
        this.createdAt = createdAt;
    }

    @Override
    public String toString() {
        return "Student{" +
                "id='" + id + '\'' +
                ", rollNumber='" + rollNumber + '\'' +
                ", firstName='" + firstName + '\'' +
                ", lastName='" + lastName + '\'' +
                ", email='" + email + '\'' +
                ", course='" + course + '\'' +
                ", gpa=" + gpa +
                ", skills=" + skills +
                '}';
    }
}

Step 05 / 10

Create the Student Repository

Spring Data provides the powerful MongoRepository interface, which supplies complete CRUD operations out of the box without writing a single line of implementation!

🎯 Goal: Extend MongoRepository<Student, String>, add derived finder methods, and understand custom MongoDB JSON queries.

1. Understanding MongoRepository

By declaring an interface that extends MongoRepository<T, ID>, Spring Data creates a proxy bean at runtime containing pre-implemented methods:

Method Description MongoDB Operation
save(student) Inserts if ID is null; updates if ID already exists db.students.insertOne() or replaceOne()
findById(id) Retrieves single document wrapped in Optional db.students.findOne({ _id: ObjectId(...) })
findAll() Retrieves all documents in the collection as a List db.students.find({})
deleteById(id) Deletes document by primary key db.students.deleteOne({ _id: ObjectId(...) })
existsById(id) Checks if document with given ID exists db.students.countDocuments(...) > 0

2. Complete StudentRepository.java Implementation

Create src/main/java/com/example/studentmongodb/repository/StudentRepository.java:

package com.example.studentmongodb.repository;

import com.example.studentmongodb.model.Student;
import org.springframework.data.mongodb.repository.MongoRepository;
import org.springframework.data.mongodb.repository.Query;
import org.springframework.stereotype.Repository;

import java.util.List;
import java.util.Optional;

@Repository
public interface StudentRepository extends MongoRepository<Student, String> {

    // Derived Query: Find student by unique email
    Optional<Student> findByEmail(String email);

    // Derived Query: Find student by unique roll number
    Optional<Student> findByRollNumber(String rollNumber);

    // Derived Query: Find students by course (Case-insensitive)
    List<Student> findByCourseIgnoreCase(String course);

    // Derived Query: Find students with GPA greater than or equal to a threshold
    List<Student> findByGpaGreaterThanEqual(Double minGpa);

    // Custom MongoDB JSON Query: Filter by course and minimum GPA
    @Query("{ 'course': ?0, 'gpa': { '$gte': ?1 } }")
    List<Student> findStudentsByCourseAndMinimumGpa(String course, Double minGpa);

    // Custom Query: Find students containing a specific skill in their array
    @Query("{ 'skills': { '$regex': ?0, '$options': 'i' } }")
    List<Student> findBySkill(String skillName);
}

3. How Derived Query Methods Work

Notice methods like findByCourseIgnoreCase or findByGpaGreaterThanEqual. You never wrote SQL or Mongo queries for them! Spring Data parses the method name keywords (findBy + [Property] + [Condition]) and automatically translates them into BSON queries at runtime.

2. Complete StudentService.java Implementation

Create src/main/java/com/example/studentmongodb/service/StudentService.java:

package com.example.studentmongodb.service;

import com.example.studentmongodb.exception.ResourceNotFoundException;
import com.example.studentmongodb.model.Student;
import com.example.studentmongodb.repository.StudentRepository;
import org.springframework.stereotype.Service;

import java.util.List;

@Service
public class StudentService {

    private final StudentRepository studentRepository;

    // Dependency Injection via constructor
    public StudentService(StudentRepository studentRepository) {
        this.studentRepository = studentRepository;
    }

    // CREATE: Save a new student with validation
    public Student createStudent(Student student) {
        // Prevent duplicate roll numbers
        if (studentRepository.findByRollNumber(student.getRollNumber()).isPresent()) {
            throw new IllegalArgumentException("Student with roll number " + student.getRollNumber() + " already exists!");
        }

        // Prevent duplicate emails
        if (studentRepository.findByEmail(student.getEmail()).isPresent()) {
            throw new IllegalArgumentException("Student with email " + student.getEmail() + " already exists!");
        }

        // Ensure id is null so MongoDB generates a fresh ObjectId
        student.setId(null);
        return studentRepository.save(student);
    }

    // READ ALL: Retrieve every student document
    public List<Student> getAllStudents() {
        return studentRepository.findAll();
    }

    // READ ONE: Retrieve student by ID or throw 404
    public Student getStudentById(String id) {
        return studentRepository.findById(id)
                .orElseThrow(() -> new ResourceNotFoundException("Student not found with ID: " + id));
    }

    // UPDATE: Modify an existing student
    public Student updateStudent(String id, Student updatedData) {
        Student existing = getStudentById(id);

        // Check if updating to an email already taken by someone else
        studentRepository.findByEmail(updatedData.getEmail()).ifPresent(found -> {
            if (!found.getId().equals(existing.getId())) {
                throw new IllegalArgumentException("Email " + updatedData.getEmail() + " is already in use by another student!");
            }
        });

        // Update fields
        existing.setFirstName(updatedData.getFirstName());
        existing.setLastName(updatedData.getLastName());
        existing.setEmail(updatedData.getEmail());
        existing.setCourse(updatedData.getCourse());
        existing.setGpa(updatedData.getGpa());
        if (updatedData.getSkills() != null) {
            existing.setSkills(updatedData.getSkills());
        }

        return studentRepository.save(existing);
    }

    // DELETE: Remove student by ID
    public void deleteStudent(String id) {
        Student student = getStudentById(id);
        studentRepository.delete(student);
    }

    // SEARCH: Filter by Course
    public List<Student> getStudentsByCourse(String course) {
        return studentRepository.findByCourseIgnoreCase(course);
    }

    // SEARCH: Filter by minimum GPA
    public List<Student> getStudentsByMinGpa(Double minGpa) {
        return studentRepository.findByGpaGreaterThanEqual(minGpa);
    }

    // SEARCH: Filter by Skill
    public List<Student> getStudentsBySkill(String skill) {
        return studentRepository.findBySkill(skill);
    }
}
BEST PRACTICE Notice constructor injection: public StudentService(StudentRepository studentRepository). In modern Spring Boot, field injection (@Autowired private StudentRepository repo;) is discouraged because constructor injection enables clean unit testing and immutable fields.

Complete StudentController.java Code

Create src/main/java/com/example/studentmongodb/controller/StudentController.java:

package com.example.studentmongodb.controller;

import com.example.studentmongodb.model.Student;
import com.example.studentmongodb.service.StudentService;
import jakarta.validation.Valid;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

import java.util.List;

@RestController
@RequestMapping("/api/students")
@CrossOrigin(origins = "*") // Allows calls from frontend apps
public class StudentController {

    private final StudentService studentService;

    public StudentController(StudentService studentService) {
        this.studentService = studentService;
    }

    // 1. CREATE: POST /api/students
    @PostMapping
    public ResponseEntity<Student> createStudent(@Valid @RequestBody Student student) {
        Student created = studentService.createStudent(student);
        return new ResponseEntity<>(created, HttpStatus.CREATED);
    }

    // 2. READ ALL: GET /api/students
    @GetMapping
    public ResponseEntity<List<Student>> getAllStudents() {
        List<Student> students = studentService.getAllStudents();
        return ResponseEntity.ok(students);
    }

    // 3. READ ONE: GET /api/students/{id}
    @GetMapping("/{id}")
    public ResponseEntity<Student> getStudentById(@PathVariable String id) {
        Student student = studentService.getStudentById(id);
        return ResponseEntity.ok(student);
    }

    // 4. SEARCH / FILTER: GET /api/students/search?course=Computer%20Science&minGpa=3.5
    @GetMapping("/search")
    public ResponseEntity<List<Student>> searchStudents(
            @RequestParam(required = false) String course,
            @RequestParam(required = false) Double minGpa,
            @RequestParam(required = false) String skill) {

        if (course != null) {
            return ResponseEntity.ok(studentService.getStudentsByCourse(course));
        } else if (minGpa != null) {
            return ResponseEntity.ok(studentService.getStudentsByMinGpa(minGpa));
        } else if (skill != null) {
            return ResponseEntity.ok(studentService.getStudentsBySkill(skill));
        }
        return ResponseEntity.ok(studentService.getAllStudents());
    }

    // 5. UPDATE: PUT /api/students/{id}
    @PutMapping("/{id}")
    public ResponseEntity<Student> updateStudent(
            @PathVariable String id,
            @Valid @RequestBody Student student) {
        Student updated = studentService.updateStudent(id, student);
        return ResponseEntity.ok(updated);
    }

    // 6. DELETE: DELETE /api/students/{id}
    @DeleteMapping("/{id}")
    public ResponseEntity<Void> deleteStudent(@PathVariable String id) {
        studentService.deleteStudent(id);
        return ResponseEntity.noContent().build();
    }
}

Annotation Recap

@RestController

Combines @Controller and @ResponseBody so every method return value is automatically serialized into JSON.

@Valid

Enforces the validation annotations on Student (such as @NotBlank and @Email). If invalid, Spring automatically returns a 400 Bad Request.

@PathVariable vs @RequestParam

@PathVariable extracts values embedded in the URI path (/api/students/123). @RequestParam reads query parameters (?course=CS).

2. Complete GlobalExceptionHandler.java

Create src/main/java/com/example/studentmongodb/exception/GlobalExceptionHandler.java:

package com.example.studentmongodb.exception;

import jakarta.servlet.http.HttpServletRequest;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.validation.FieldError;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

import java.util.HashMap;
import java.util.Map;

@RestControllerAdvice
public class GlobalExceptionHandler {

    // 1. Handle ResourceNotFoundException -> 404 NOT FOUND
    @ExceptionHandler(ResourceNotFoundException.class)
    public ResponseEntity<ErrorResponse> handleNotFound(ResourceNotFoundException ex, HttpServletRequest request) {
        ErrorResponse error = new ErrorResponse(
                HttpStatus.NOT_FOUND.value(),
                "Not Found",
                ex.getMessage(),
                request.getRequestURI()
        );
        return new ResponseEntity<>(error, HttpStatus.NOT_FOUND);
    }

    // 2. Handle IllegalArgumentException (Duplicates, bad state) -> 400 BAD REQUEST
    @ExceptionHandler(IllegalArgumentException.class)
    public ResponseEntity<ErrorResponse> handleBadRequest(IllegalArgumentException ex, HttpServletRequest request) {
        ErrorResponse error = new ErrorResponse(
                HttpStatus.BAD_REQUEST.value(),
                "Bad Request",
                ex.getMessage(),
                request.getRequestURI()
        );
        return new ResponseEntity<>(error, HttpStatus.BAD_REQUEST);
    }

    // 3. Handle Bean Validation Errors (@Valid failure) -> 400 BAD REQUEST
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<Map<String, Object>> handleValidationExceptions(MethodArgumentNotValidException ex, HttpServletRequest request) {
        Map<String, String> validationErrors = new HashMap<>();
        for (FieldError fieldError : ex.getBindingResult().getFieldErrors()) {
            validationErrors.put(fieldError.getField(), fieldError.getDefaultMessage());
        }

        Map<String, Object> response = new HashMap<>();
        response.put("status", HttpStatus.BAD_REQUEST.value());
        response.put("error", "Validation Failed");
        response.put("details", validationErrors);
        response.put("path", request.getRequestURI());

        return new ResponseEntity<>(response, HttpStatus.BAD_REQUEST);
    }

    // 4. Generic Fallback -> 500 INTERNAL SERVER ERROR
    @ExceptionHandler(Exception.class)
    public ResponseEntity<ErrorResponse> handleGeneralException(Exception ex, HttpServletRequest request) {
        ErrorResponse error = new ErrorResponse(
                HttpStatus.INTERNAL_SERVER_ERROR.value(),
                "Internal Server Error",
                ex.getMessage(),
                request.getRequestURI()
        );
        return new ResponseEntity<>(error, HttpStatus.INTERNAL_SERVER_ERROR);
    }
}

Arrays / Lists Requires @ElementCollection or @OneToMany Native embedded arrays directly in document

Frequently Asked Questions

Why didn't we use @GeneratedValue for the ID field?
In MongoDB, when a document is saved with a null id, the MongoDB driver automatically creates a unique 12-byte ObjectId and assigns it to _id. Spring Data MongoDB automatically detects this and assigns the generated hexadecimal string back to your entity.
How do embedded sub-documents work in MongoDB?
Unlike relational tables that require foreign keys, you can define another Java class (e.g., Address with street, city, zipCode) and include it as a field inside Student: private Address address;. Spring Data will serialize it directly as a nested JSON object!
What is the difference between MongoRepository and MongoTemplate?
MongoRepository provides high-level declarative CRUD and derived queries with zero boilerplate. MongoTemplate is Spring's lower-level fluent template that offers fine-grained control over complex aggregations, bulk operations, partial updates ($set, $inc), and custom criteria.
